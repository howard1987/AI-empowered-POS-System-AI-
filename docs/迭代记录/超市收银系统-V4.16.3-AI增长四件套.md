# 超市收银系统 V4.16.3 — AI 增长四件套（P11）

> 对应需求：会员画像 AI 建模 / 节日表外部导入 / 外部商品数据库导入 / 综合多因子预测（一次性全量落地）
> 迁移：`backend/db/073_v4163_ai_growth.sql`（幂等）

## 一、会员 AI 画像（问题 1）
**聚合**（纯 SQL，数据不出店）：
- 近 180 天消费 TOP N 会员（`ai.member.portrait.top`，默认 30，防大模型逐人生成阻塞）
- 指标：订单数 / 消费额 / 客单价 / 余额 / 距上次消费天数
- 常购商品 TOP3（按数量）、偏好品类 TOP3、到店时段（上午/中午/下午/晚间众数）、价格带（<40 日常小额 / 40~80 中客单 / ≥80 高客单）、近 30 天 vs 前 30 天趋势（上升/平稳/下滑/新客）、流失前兆（30 天未消费或趋势下滑）

**建模**：
- 结果缓存 `member_portraits`（store_id+member_id 唯一，重复生成覆盖）
- Ollama 开启（ai.llm.enabled）时逐人生成 80 字内人话画像（消费习惯/偏好/流失风险/一句营销建议），失败自动回落规则拼接文案，engine 字段记录 rule/ollama
- 入口三处：`POST /brain/member-portraits`（批量生成）、`GET /brain/member-portraits/:memberId`（单人读取）、决策中心按钮「👥 会员画像」；每日 06:00 refresh 闭环自动刷新
- 前端：会员详情抽屉新增「🤖 AI画像」页签（画像正文 + 4 KPI + 常买/品类/时段/流失标签 + 重新生成按钮；无画像时空态引导生成）

## 二、节日表外部导入（问题 2）
- 设置项 `ai.holiday.custom`（JSON 数组，设置页 AI赋能-「节日表与会员AI画像」小节直接编辑/粘贴）：
  `[{"name":"店庆日","m":9,"d":20,"factor":1.5}]`（y 可选指定年份；factor 客流系数 1~3）
- 引擎 holidayStock 读取：与内置节日表**合并**，同名以自定义为准；非法行（月日越界）静默跳过
- 当日去重逻辑不变；无预测数据时提示先跑销量预测

## 三、外部商品池（问题 3）
**定位**：与商品档案批量导入（直接建档）不同的「参考数据库」——导入供应商全量目录/行业条码库，**不进正式档案**；建档/扫码未命中本店库时先查池秒回补齐，再走在线源，两者互补。

- 表 `ref_product_pool`：条码唯一，名称/规格/单位/品牌/类别/参考价/来源/批次/被查次数
- `POST /products/pool/import`：xlsx/CSV base64（同 import-file 宽表头匹配：条码/名称 必填，规格/单位/品牌/类别/售价 可选；缺规格单位自动从名称提取）；按条码 upsert（重复导入更新）；条码须 8~14 位数字，无效行跳过并计数
- **编码自适应（重要坑）**：SheetJS 对 CSV buffer 无论默认还是 codepage 936 都会乱码（本机实测），已改为 ZIP 魔数判断 xlsx 直读；CSV 文本先用 TextDecoder UTF-8 解码、表头识别失败再 GBK 解码重试
- `GET /products/pool?q=&size=&offset=`：条码/名称/品牌/类别模糊搜索
- 查询链接入：`lookupBarcodeBig` 顺序变为 **本店档案 → 本店确认缓存（纠错回写） → 外部商品池（本地秒回，hits+1） → mxnzp → OpenFoodFacts → 爬虫**；池命中标记 source='外部商品池（导入参考数据请核对）'
- 前端：商品档案工具栏「🌐 外部商品池」按钮 → 抽屉弹窗（搜索列表 + 文件导入 + 导入结果 toast）

## 四、多因子预测（问题 6）
预测公式升级（baseline 引擎）：
```
预测量 = 星期基线 × 趋势 × 地点系数 × 天气修正
天气修正 = 1 − w + w × 当日天气客流系数（w = ai.forecast.weather_weight，默认 0.3）
地点系数 = ai.forecast.location_factor（默认 1.0，>1 上调如社区密集，<1 下调如位置偏）
```
- 天气客流系数来自 V4.16.1 weather.service（雨 0.9/雪 0.8/高温冷饮 ↑ 等按品类；预测层用整体 traffic 客流系数）
- `factors` 快照留痕：weekday/trend/loc/weather/traffic，可回溯每个因子贡献
- **回测**：forecast 返回近 14 天已回填实际销量快照的 MAPE（按提前 1~7 天分组），决策中心预测结果显示「回测 MAPE x%（提前N天 x%）」
- lgbm 引擎开关不变（预留，服务可达才启用）；设置项在「补货与销量预测」小节
