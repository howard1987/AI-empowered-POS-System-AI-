# 超市收银系统 V4.17.0 · P13 签字样本库专项

> 日期：2026-09-11　|　上游：V4.16.6 四项复查中用户点名"签字样本下一期单独理"　|　路线图编号 P13

## 一、问题（P13 立项四项）

1. **同名多行**：样本库一行=一个模板，同一人可出现 N 行（Web 预采集一行、手机三连采经远程签字流又一行、现场补签自动采集再一行），1 人 N 行各 1 遍图。
2. **分类错乱**：`personCatOf` 兜底把"三不靠"（无供应商、无员工绑定）一律落「大客户人员」——超级管理员的样本被冤标成大客户人员/操作员。
3. **采集不去重**：预采集端点 `POST /purchase/signatures` 无脑 INSERT 新行，与现场补签的 `collectIntoTemplates`（会按人合并）口径不一致；同一张图重复采也重复计遍数。
4. **占位样本无治理**：乱签门槛只有"笔画≥2 且墨量>0.1%"，纯色块/近空白占位图能入库，且无事后检测、无重采通道。

需求决策（你问我答定稿）：同人判定=归一化姓名+人员分类+供应商；分类自动推断+待确认+手动兜底；存量脚本回填+物理合并；无效样本双阈值打标+重采替换+批量清理；版本 V4.17.0 全链路一期。
