## 一、逐项落地清单

### ① 漏扫检测 MVP（能力全景 1.2 / 4.1）——默认开
**文件**：`src/modules/ai.antileak.ts`（新）｜ `member-app.module.ts`（挂接）｜ `db/045`（antileak_alerts 表）

| 端点 | 说明 |
|---|---|
| `POST /antileak/verify` | 通用校验：AI 识别逐件 count vs 结算件数 + 称重理论重 vs 实秤重（店员端仅提示不拦单） |
| `GET /antileak/alerts` | 差异告警列表（待复核优先） |
| `POST /antileak/alerts/:id/handle` | 复核处置：已放行 / 已拦截（留痕审计） |

- **件数校验**：严格模式（缺 1 件即差异）/ 宽松模式（缺 ≥2 才拦），`antileak.count.strict` 切换
- **重量校验**：容差 `antileak.weight.tolerance`（默认 ±0.05kg）
- **自助收银挂接**：`/m/self-checkout` 新增可选参数 `aiItems` / `weightKg` / `force`；差异即 **41001 暂停待店员复核**；`force=true` 可强推但必落「待复核」告警（老板端防损页可见）
- **PWA 店员端**：AI 拍多件加购后自动调 verify，差异 toast 提醒（不拦单，决策权在人）

### ② 支付账单导入对账（能力全景 4.2）——默认开
**文件**：`src/modules/finance.recon.ts`（新）｜ `db/045`（payment_bills + bill_recon_runs 表）

| 端点 | 说明 |
|---|---|
| `POST /finance/recon/bill/import` | 微信/支付宝账单 CSV（粘贴或传文件）→ 解析入库 → 自动对齐 → 出对账单 |
| `GET /finance/recon/runs` / `runs/:id` | 批次列表 / 详情（差异清单） |
| `POST /finance/recon/bills/:id/ignore` | 差异行人工忽略 |

- **解析**：通用宽松解析（自动找含「单号+金额」的表头行；只对收入行对账，退款/关闭/失败行自动跳过并计入 skipped）
- **对齐规则**：①平台交易单号精确命中 `sale_payments.external_no` → ②金额相等 + 本地订单时间 ±`window_seconds`（默认 300s）内
- **差异口径**：金额差异（账单有本地无——先查漏单/私收）、疑似重复（同笔本地收款被多行匹配——平台退款拆行）
- **防重复导入**：同渠道同交易单号二次导入直接拒绝
- **老板端**：报表页新增「💰 账单对账」入口（导入 + 批次列表 + 差异行点击忽略）

### ③ AI 选品建议（能力全景 3.3）——默认开
**文件**：`aibrain.engine.ts` 新增第 10 项应用 `assortment`（域 `选品`，迁移补枚举值）

- **淘汰清单**：观察窗口（默认 30 天）零动销且库存 ≥10，或周转天数 >60 天且动销 ≤2 天 → 「清仓 8 折去化 / 停补淘汰」建议
- **品类扩容**：品类收入占比 >12% 且 > 其 SKU 占比 1.8 倍 → 「扩充该品类 SKU」建议
- 与补货/定价同构：建议进 `ai_suggestions` 待处理流（执行/否决留痕），每日 06:00 随全量刷新自动运行，也可 `POST /brain/run/assortment` 手动触发

### ④ qa 预置问题（能力全景 2.2 改进项）——即开即用
**文件**：`aibrain.module.ts` 新增 `GET /brain/qa/presets`；boss 端新增「🗣️ 经营问答」页

- 预置 9 个高频问题一键问：今日毛利 / 销售额 / 近7天热销榜 / 缺货清单 / 临期批次 / 退款 / 会员新增 / 待处理补货建议 / 日报摘要
- 保留自由输入框（规则引擎路由 + 知识库检索 + 可选 LLM 润色，链路不变）

### ⑤ 语音查价单点（能力全景 2.1 单点 MVP）——**默认关**
**文件**：`public/pwa/voice.js`（新）｜ `checkout.js` 收银台新增「🎤 语音查价」按钮

- 全链路**本地零云端**：浏览器 Web Speech API 中文识别（Chrome/Edge + HTTPS）→ 口语清洗（去"请问/多少钱/谢谢"）→ 价目表缓存查价 → speechSynthesis TTS 报价
- 开关 `voice.price.enabled`：老板端设置页可开；未开启时按钮提示引导；识别不到商品语音反馈
- 设计意图：先让店员试用验证真伪需求，再谈语音下单（方案 Phase 3 单点验证路线）

### ⑥ 预测引擎升级 LightGBM（能力全景 3.1）——**默认关，数据门槛**
**文件**：`aibrain.engine.ts` forecast 引擎分支 + `lgbmForecast()`；`backend/ai-forecast-svc/`（Python 微服务骨架）

- 开关 `ai.forecast.engine`：`baseline`（现役星期系数+趋势）| `lgbm`
- **三重闸门**：①引擎开关切到 lgbm ②全店累计有流水天数 ≥ `ai.forecast.lgbm.min_days`（默认 56 天=8 周）③本地服务 `ai.forecast.lgbm.url` 可达——任一不满足自动回落 baseline，**预测主链路永不断**
- 微服务：FastAPI + LightGBM，逐商品滞后特征（lag1/3/7、7/14 日均值、星期几）回归，样本 <14 天自动退回与后端 baseline 同构的保底算法；lightgbm 未装也能跑（fallback）
- 部署：`cd backend/ai-forecast-svc && pip install -r requirements.txt && uvicorn app:app --port 9101`
