- **A5 调用核查结论与整改**：
  - 入库/退货/采购订单：详情接口自带 `sign_image_path / approver_sign_path`，A5 固定版式已落「操作员签字/审批人」槽位 ✓

  - 签名落位升级：按槽位顺序（操作员签字→审批人→经办人签字→盘点人签字→店长签字）逐张落位，剩余签名并进「✍️ 电子签名」块同行展示；多张签名照同行显示
  - **hiprint v3 可视化模版打印（此前完全不带签名）**：签名图暴露为模版字段 `signImg`；模版未绑定时兜底在页面追加电子签名行——两条打印路径（固定版式 + 可视化模版）都带签名
  - 查询失败/无签名时照常出单（签名栏留白手签），绝不阻断打印
  - 证据链数据核查：inbound 50 / order 5 / return 6 / loss 2 / count 1 / 对账确认 1 均有 image_path，五场景证据链完整
