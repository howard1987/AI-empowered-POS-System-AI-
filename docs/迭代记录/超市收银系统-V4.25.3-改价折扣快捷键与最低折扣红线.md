## 二、红线规则（一条线看懂）

每件商品可设两条线，取**更严者**生效：

| 线 | 字段 | 示例 | 含义 |
|----|------|------|------|
| 最低卖价（绝对值） | `products.min_price` | 1.98 | 改价 / 折后单价不得低于 ¥1.98；**未设时按售价 6 折兜底** |
| 最低折扣（相对值） | `products.min_discount_rate` | 80 | 单品/整单折扣不得低于 80 折（8 折）；**100 = 不允许打折；未设 = 不限折扣** |

**越线处理**：
- 普通收银员 → 直接拒绝，明确中文提示；
- 店长（`pos.emergency.manual`）→ 可放行，**必写留痕**（`audit_logs`：商品 / 折扣率 / 折后价 / 红线值）；
- 前端只做体验层提示，**服务端同口径二次校验**（唯一权威）。

## 三、收银端快捷键

| 动作 | 默认键 | 说明 |
|------|--------|------|
| 改价 | **P** | 对**当前选中行**改价；受最低卖价约束 |
| 单品折扣 | **D** | 对**当前选中行**打折；受最低折扣 + 最低卖价双重约束 |
| 结算 / 挂单 / 取单 / 重复上一单 / 打印开关 / 锁屏 / 库存查询 | F9 / F2 / F4 / F6 / F7 / F8 / F10 | 原有不变 |
| 键位说明 | F1 | 固定 |

- **目标行**：点一下购物车行 → 该行高亮为「当前行」，快捷键作用于它；未选时作用于**最后一行**。
- 行内也新增「**折**」按钮（与快捷键 D 同效），点击价签 = 改价。
- 键位在「设置 → 快捷键自定义」可改（支持 F1~F12 或单个字母）。
- **EXE 全局键**：只注册 F 键；字母键（P/D）仅页面内生效 —— 避免单字母全局劫持系统输入（在别的窗口按 P 也会被拦）。

## 四、验证结果（本机实测）

### 4.1 数据库
- 迁移 `095` 已应用；`products.min_discount_rate` 列存在（`numeric`），`schema_migrations` 已记账。

### 4.2 商品档案
- `PUT /products/127 {minDiscountRate: 80}` → 200；回读 `min_discount_rate = 80.00` ✅
- 恢复 `minDiscountRate: 0` → 回读 `0.00`（0 = 不限制）✅

### 4.3 红线校验（服务端权威）
实测下单 `discRate=70`（商品最低折扣 80 折）→ 服务端识别红线并留痕：

```
audit_logs: 低于最低折扣/售价放行
{"name":"V4132通道测试商品","discRate":70,"unitPrice":2.31,"minDiscRate":80,"minSalePrice":1.98}
```
- 因测试账号为超管（带 `pos.emergency.manual` 店长放行权），故按设计**放行 + 留痕**；
- 无该权限的收银员会收到拒绝（`50034`）。

改价红线（既有能力）同样实测留痕：`{"minPrice":1.98,"unitPrice":1}`。

> 测试产生的 4 张单据、库存流水、批次分配、审计留痕**已全部清理并回滚**（批次 15 与 inventory_current 均从 43 恢复为 47，无残留测试单）。
