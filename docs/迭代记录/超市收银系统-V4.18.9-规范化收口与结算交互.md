## 1. 错误码规范化（后端）

- **CORS 403**（main.ts）：弃用 `enableCors` 回调抛错写法（会被兜底过滤器包成 500），改为自研中间件：
  回环/`null` 来源放行（带 credentials 头，OPTIONS→204），其余来源 `403 {code:40300, msg:'CORS 未授权来源'}`。
- **参数类型混淆 40003**（common/http.ts）：DTO 层为纯接口无装饰器，类型混淆以 TypeError 落到过滤器；
  现 `TypeError → 400 {code:40003, msg:'请求参数类型或取值不合法'}`，详情仍进 logs/error.log；未知异常保持 50000。

**实测**：外网 Origin OPTIONS → 403/40300；回环 preflight → 204；`items:"not-an-array"` checkout → 400/40003。

## 3. 结算交互与静默打印（收银端，SW v55）

1. **实收自动聚焦**：结算弹窗打开后 80ms 内聚焦「顾客实收」并全选，扫码枪/键盘直接输入，免鼠标点击。
2. **回车即收款**：实收行内按 Enter = 点「确认收款」（实收不足仍按原口径拦截）。
3. **静默打印链路**（已绑 POS-80 系统驱动直发后默认即静默，本次收口兜底行为）：
   `F7 开 → PwaPrinters.autoPrint`：串口/USB-RAW/USB-WebUSB/网口四级直驱全部静默；
   全部不可用才回落 iframe 打印（浏览器限制必有预览，属降级路径并明示）。
4. **F7 小票打印开关**：新设置 `pos.cashier.print`（迁移 087，默认开）；F7 一键开/关并留痕（断网时本机内存生效），
   关闭时确认弹窗显示「小票打印已关（F7 开启）」；**收款/钱箱/语音不受影响**；收银设置面板同步可调。
5. **PwaReceipt 兜底小票接 v3**：打印中心「小票模版」的可视化排版（hiprint v3）现在对浏览器兜底通道同样生效——
   `hpToEls` 同映射 HTML 纵向流（文本/kv/字段/分隔线/明细表/实收大字；二维码以居中单号行替代），无 v3 版式时回落固定版式。
