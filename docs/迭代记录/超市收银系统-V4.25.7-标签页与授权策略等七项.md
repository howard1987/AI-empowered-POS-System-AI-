## 二、逐项说明

### 1. 授权策略后台可配（设备管理分组）
新增两个设置（迁移 097 种子，收银端 `loadSettings` 自动拉取生效）：

| 设置项 | 选项 | 默认 |
|--------|------|------|
| **改价授权复用** `pos.price.auth_reuse` | `batch` 一次授权，本单连续改价免再输码（票据 120 秒 · 结算作废）；`once` 每次改价都弹窗输授权码 | `batch` |
| **店长本人免输授权码** `pos.price.auth_self` | `off` 店长本人操作也需输码（责任最严）；`on` 持授权资格者本人操作自动授权（免弹窗，仍留痕） | `off` |

- 「店长本人免输」的实现：新接口 `POST /auth/authorize-self`——持 `pos.price.authorize` 者用登录态换票（免授权码），审计 `auth.price_authorize_self` 留痕。
- 老板端「系统设置 → 设备管理」里这两项为**下拉选择**（说人话的中文选项），保存即生效，收银端下次加载设置自动同步。

### 2. 系统初始化页签移到最后
- 系统设置页签顺序改为「系统初始化」固定排末位（低频、危险操作，防误点）。

### 3. 后台多标签页导航条（参考银豹）
- 打开的页面自动在内容区顶部生成**标签**：`● 图标 名称 ✕`。
- 点标签切换（页面状态保留，切回不重新渲染）；点 `✕` 关闭；关闭当前页自动跳到相邻标签。
- 「首页」固定不可关闭；标签列表存本地（刷新后保留）；退出登录自动清空。
- 样式：未激活灰点，激活主色实心点 + 高亮边框。

### 4. 收银端音色
- 下拉新增第一项：**「🔊 引擎语音（服务器神经语音·离线拟真）」**（值 `__engine__`）——强制走服务端 piper 神经语音，探测/合成失败自动无缝回落本机音色。
- 修复下拉超出弹窗右边界：`.kv` 行允许收缩换行、`.v` 限宽 68%、`select` 限宽 100%；设置弹窗加宽到 `min(680px, 96vw)`。
- 「跟随老板端设置」「⭐ 自动择优」「本机音色列表」保持不变。

### 5. 店长授权码移到后台
- **后台「员工与角色」**：员工表格新增「授权码」列（已设置/未设置），操作列新增「授权码」按钮——设置/修改/清除（清除需二次确认）。
- 后端新接口 `POST /auth/employees/:id/auth-code`（需 `staff.manage` 权限；传空 = 清除）；员工列表返回 `authCodeSet`。
- **收银端设置页的授权码入口已移除**，改为只读提示「在后台『员工与角色 → 授权码』设置」；授权弹窗里的提示文案同步更新。

### 6. 加车闪 cmd 黑窗（根因修复）
- 后端 piper 语音合成 `spawn(piper.exe)` 未加 `windowsHide` → 收银端每次走引擎语音播报（加车报价）都会闪一下 cmd 控制台。
- 修复：`windowsHide: true` + `stdio:['pipe','ignore','pipe']`（stdout 本就写文件，直接忽略）。

### 7. 加车播报去掉库存
- 加车只播「**商品名，价格元**」；「库存仅剩 X / 无库存」只在「🎤 问价」场景播报（原有行为不变）。

3. **系统设置**：页签「系统初始化」在最后；「设备管理」里可见两个授权策略下拉。
4. **员工与角色**：员工表有「授权码」列，给店长工号设授权码。
5. **收银台**（Ctrl+F5，版本 V4.25.7）：
