## 3. 迁移 082（批1 开放键）

- `sale_items.custom_name VARCHAR(100)`（可空）：开放键临时行品名，展示层 `COALESCE(custom_name, p.name)`
- 每店占位商品（`barcode='OPENKEY'`、`goods_no='OPENKEY-'+store_id`、不记库存、售 0 元、`min_price=0`）：
  `sale_items.product_id NOT NULL` 口径不改表结构，既有报表/退货/对账 JOIN 零破坏，开放键营收归「开放键临时行」
- 价目表 `WHERE barcode IS DISTINCT FROM 'OPENKEY'` 过滤，占位商品不进宫格/搜索

## 4. 后端（sales.module / pos.module）

| 能力 | 实现 |
|---|---|
| 开放键临时行 | `items[]` 支持 `{customEntry:true, name, qty, unitPrice>0, lineRemark?}`——服务端解析/惰性创建占位商品，成本 0 不碰库存，`custom_name` 落库 |
| 赠品行 | `items[]` 支持 `{gift:true, lineRemark:原因}`——需 `pos.price.manual` 权限，0 元出库、库存照扣成本照记，`audit` 留痕（module=收银 action=手工赠品 detail 含原因），行备注自动缀「赠品:」 |
| 重复上一单 | `GET /pos/last-order`：本收银员最近一笔已完成单的行快照（过滤 OPENKEY 占位行） |
| 扫码查库存 | `GET /pos/product-detail?productId=`：商品 + 实时库存 + 在库批次（到期/余量，FIFO 序） |

## 5. 前端（pwa/cashier.js）

- **开放键**：「全部商品」标签行「开放键 · 手输杂货」按钮 → 品名*/单价*/数量/备注 → 临时行上车（标「开放键」蓝 tag）
- **赠品行**：购物车行「赠」按钮（需 pos.price.manual）→ 原因弹窗 → 0 元 + 红「赠」tag；再点撤销；行备注自动记原因
- **行备注**：购物车行「注」按钮 → 备注（行内「注」tag + 全文展示），结算与小票留痕
- **重复上一单**：顶栏按钮 → 确认 → 按原成交价逐行重上车（`snapToLines` 复原 manualPrice/gift/remark）
- **扫码查库存**：商品卡点「库存角标」→ 详情弹窗（库存/批次/到期）+「加入购物车 ×1」顺手加车
- **整单备注**：结算弹窗「整单备注」输入框 → 落单 remark（挂账原因/顾客称呼）
- **快照统一**：`snapFromCart()/snapToLines()` 支持开放键/赠品/备注三种新行状态，挂单、挂起单（90s 转挂起）、重复上一单三链路共用；促销预览跳过开放键行（无 productId 语义）
- 整单备注生命周期：收款确认时捕获 → 落单后清空；离线暂存/挂起转存同样清空
