## 二、关键实现说明

### ⑥ 首次管理员引导（不再写死 ADMIN）
- `init-db.ts` 只做**检测**（是否已有绑定「超级管理员」角色的在职员工），不再自动建账号；无则打印「请打开登录页按提示创建管理员」。
- 超管判定从 `emp_no === 'ADMIN'` 改为 **绑定「超级管理员」角色**（`isSuperAdmin(empId)`），历史 ADMIN 账号本就绑了该角色，行为不变；设备授权豁免、JWT `* ` 通配、启动告警三处一并改口径。
- `POST /auth/bootstrap-admin` 仅在无管理员时可用（有则 40305），创建后绑定超管角色并**直接签发 token 完成一次登录**，省去再输一遍。工号规则 2~32 位字母/数字/下划线/中划线，密码走既有强度策略。

### ⑨ PIN 快速登录
- 设置 PIN 必须提供**当前登录密码**，PIN 为 4~8 位数字、bcrypt 存储；改/清 PIN 均需密码。
- `pin-login` 独立频控：连错 5 次锁 15 分钟；未设置 PIN 返回 41011，前端自动退回密码模式。
- 登录页：勾选「记住 PIN」→ 登录成功后用刚输入的密码作凭证写 PIN；下次打开自动进 **PIN 模式**（标签/占位/按钮文案都变），可点「用密码登录」切回。

### ② 退班向导（交接班 → 日结 → 退出）
- 第 1 步交接班：无进行中班次 → 直接进日结；有班次 → 显示应答金额 + 实点输入 + 差异，主按钮「确认交班并打印」、**「无异常，自动交班」= 以系统应答金额为实点（差异 0）一键交班并打印交接单**。
- 第 2 步日结：自动拉当日 `/pos/daily`，「打印日报并继续」/「跳过日结」。
- 第 3 步：确认「退出登录」回登录页（彻底关闭在登录页点 ✕）。每步都有「返回收银台」。

### ⑦ 强 Kiosk
- 渲染层登录后读 `pos.desktop.kiosk_topmost` → `DesktopShell.setKioskTopmost(on)` → 主进程 `applyKiosk()` 里 `setAlwaysOnTop(on, on ? 'screen-saver' : 'normal')`，登录态永远不置顶。
