# 超市收银系统 V4.15.9 — 可视化模版排版编辑器（hiprint 内核搬运集成）

> 日期：2026-09-10　|　前置：V4.15.8（P4 模版编辑器/P5 多联重打）　|　迁移：070

## 一、需求

模版编辑器升级为「小工具类排版编辑器」：选择模版 → 纸张类型/大小 → 拖动元素排版，带对齐辅助线、自动对齐、吸附，元素可增删/自定义，保存即打印模版。参考 vue-plugin-hiprint（`D:\Software\POS_system\vue-plugin-hiprint-main`），**直接搬运该插件作为编辑器内核**，接入我们自己的业务字段元素、精简默认元素。模版不只热敏机，还要覆盖激光/喷墨打印机。

## 二、架构

```
编辑器（Web 后台 打印中心-打印模板 Tab）
  └─ vendor/hiprint（vue-plugin-hiprint 0.0.61-beta5 UMD + jQuery + JsBarcode + stubs）
       │  设计器：拖拽/辅助线吸附/网格/缩放/旋转纸张/Ctrl+Z·Shift+Z 撤销重做/Ctrl+C·V/Delete（均为内核内建）
       │  左面板三组：基础元素(文本/直线/矩形框/图片) + 业务字段(随业务注入+示例值) + 码(条码/二维码)；单据类另有「明细表」
       │  纸张：标签 40x30/50x30/60x40/自定义；小票 58/80(宽固定高可调)；A5/A4/A3/自定义
       ▼ 保存 content = { version:3, title, hp:<hiprint JSON>, paper, options }
存储（print_templates.content jsonb，三版本兼容）
  ├─ v3：hiprint JSON（元素坐标 pt，1mm=72/25.4pt；面板宽高 mm）——现行
  ├─ v2：elements（mm 坐标，V4.15.8 末期格式）——打开编辑器自动升 v3
  └─ v1：fields 字段显隐——打开编辑器自动转默认版式，保存升级
消费端（normalizeLayoutDoc 归一为 mm 元素后渲染）
  ├─ 热敏标签 TSPL/ZPL：print.hiprint.ts → buildLayoutBytes 逐元素指令（后端）
  ├─ 热敏小票 ESC/POS：pwa/printers.js hpToEls → buildReceiptLayout 纵向流（前端）
  └─ 激光/喷墨 A5/A4：docprint.js → hiprint getHtml(data) 整页 HTML → 浏览器打印（明细表自动分页）
```

## 四、hiprint 集成要点（坑与关键决策）

1. **UMD 全局**：`window.hiprint` 由 bundle 内部赋值；外部依赖 jQuery/JsBarcode/bwip-js/io/jspdf/canvg 全部 externals→root 全局。
2. **io 桩必须自引用**：bundle 加载即执行 `window.autoConnect=!0` 与 `window.io=外部模块.io`——桩函数必须挂 `.io=self`，否则被覆盖成 undefined，`window.io(host)` 报 "not a function"。
3. **单位**：getJson 元素坐标 pt（1mm=72/25.4≈2.8346pt），面板 width/height 为 mm；fontSize 单位 pt。
4. **设计器 CSS**：dist 只带 print-lock.css（打印+design 类）；面板/属性表样式由 JS 运行时注入（style-loader 内嵌）。
5. **面板拖拽目标**是 `a.ep-draggable-item[tid=...]`，不是外层 li（Playwright 模拟拖拽要先抓准）。
6. **属性面板**（settingContainer）选中元素后才渲染；分页容器 paginationContainer 需存在。
7. 未搬入：PDF 导出(jspdf)、electron 客户端打印(socket.io)、html2canvas——均为 externals 桩，功能入口不存在。
