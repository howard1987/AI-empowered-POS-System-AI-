# 超市收银系统 V4.21.1 —— 局域网接入修复 + 收银机授权管理 + 收银端保存加固

> 版本时间：2026-09-11 深夜　｜　前置版本：V4.21.0（P16 批2）
> 触发：用户真机反馈两问题——①浏览器收银端不打单、打印开关/免预览设置"保存无效"（无提示、弹窗不关）；②同网段其他电脑/手机登录 `192.168.0.6:3100/pwa/` 报「CORS 未授权来源」，并要求后台增加收银机授权管理。

---

## 1. 问题一：设置保存"无反应"与打印疑问 —— 排查结论 + 修复

### 1.1 排查过程（先证伪"新代码坏了"）
- 用 CDP 全新浏览器（SW 正常流程）真实点击「设置→保存」：**toast「收银设置已保存并留痕」正常弹出、窗口正常关闭、DB 值正确落库、无任何 JS 异常** → 服务端代码与数据库均正常。
- 结论：用户浏览器/EXE 内运行的是 **SW 旧缓存脚本**（V4.19.0~V4.20.0 时代版本，当时 `pos.print.browser_fallback` 缺种子导致保存 40404 被单层 try/catch 静默吞掉 → 正是"点了保存没提示、窗口不关、设置像没用"的完整症状）。
- 打印侧真因：**printers 表为空（未配置默认小票机）** → 浏览器端只能走「浏览器兜底=弹预览」。配置默认机（POS-80 系统驱动直发）后，浏览器收银端同样静默直出、不再弹预览。

### 1.2 修复（cashier.js，SW v58→v59）
1. 保存 handler **外层 try/catch 兜底**：任何未预期异常都 toast「保存异常：…」，从机制上杜绝"点了没反应"。
2. 音色刷新 `PwaTTS.loadCfg(true)` 移到成功 toast 之后 fire-and-forget，界面刷新（loadSettings/renderGrid）异常只 console.warn，**不再阻断 toast 与关窗**。

### 1.3 用户侧操作指引（重要）
- **先强刷**：收银页 `Ctrl+F5`（或退出 EXE 重开），让 SW v59 新脚本生效——保存无反应即消失。
- **要静默出票**：后台「打印中心」把 POS-80 建档并设默认（USB+绑定系统打印机=后端 winspool 直发），此后**任何浏览器收银端都免预览静默出票**，F7 开关、空格免票均正常生效。未配默认机时：`浏览器兜底打印=开` 弹预览、`=关` 时明示「小票未打印」。

## 2. 问题二：局域网登录「CORS 未授权来源」—— 放行规则重写（main.ts）

### 2.1 根因
V4.18.9 自研 CORS 中间件只放行回环来源（localhost/127.0.0.1/[::1]），同网段机器（Origin=`http://192.168.0.6:3100`）与手机扫码（`https://192.168.0.6:3443`）全被 403。

### 2.2 新规则（本地化部署系统，内网来源可信）
放行：回环、**私有 IPv4**（10.x / 192.168.x / 172.16~31.x）、**mDNS 域名**（*.local，即 pos-server.local）、**同主机来源**（host 头比对，任意端口）。
保持拦截：外网域名等其余来源仍 403 {code:40300}（渗透基线不回退）。

### 2.3 其他机器登录方式（修好后）
- 收银机浏览器：`http://192.168.0.6:3100/pwa/`（或 https://pos-server.local:3443/pwa/）
- 手机扫码登录：老板端二维码指向 `https://<IP>:3443`，首次需信任自签名证书。

## 3. 收银机授权管理（迁移 090，默认关）

### 3.1 为什么不用 MAC 绑定
浏览器**拿不到 MAC**（隐私接口不暴露，且 MAC 可随意伪造、手机 Wi-Fi 有随机化）——MAC 绑定在 Web/PWA 架构下既做不到也不牢。采用更可靠的等价方案：**设备码 + UA 指纹 + 服务端审批白名单**。

### 3.2 流程
1. 老板端「设置 → 🖥️ 收银机授权」开启 `pos.device.auth`（默认关，关闭=行为与旧版完全一致）。
2. 新设备登录（账密/扫码）→ 服务端自动登记为**待授权**，登录被拒 40307 并明示**设备码**（如 DTEST0001）。
3. 管理员在授权页按设备码**通过**（可命名"1号收银机"）/ **停用**（40308 拒登录）/ **删除**（下次登录重新登记）。
4. **ADMIN 超管豁免**——保证老板永远能登录审批，防锁死；员工/店长账号均受控。
- PWA/老板端登录与扫码登录均自动携带本机设备码（localStorage 持久化 `pwa_device_code` / `boss_device_code`）。

### 3.3 实现
- 迁移 `090_v4211_pos_device_auth.sql`：`pos_devices` 表（store_id+device_code 唯一、status 待授权/已授权/已停用、ua/last_ip/last_seen_at/审批留痕）+ `pos.device.auth` 种子（bool，false）。
- `auth.module.ts`：凭证校验**通过后**才做设备校验（防未授权设备探测账号/刷待授权记录）；`login` 与 `qr-login` 同口径。
- `device.module.ts` 新增 `PosDevicesController`：GET /pos-devices（待授权优先）、POST /:id/approve、POST /:id/status、DELETE /:id，全部 `sys.settings` 权限 + audit 留痕。
- 老板端 `boss/app.js`：设置页新卡片（待审批数角标）+ `View.deviceAuth` 子页（开关/列表/审批/停用/删除/命名）。
