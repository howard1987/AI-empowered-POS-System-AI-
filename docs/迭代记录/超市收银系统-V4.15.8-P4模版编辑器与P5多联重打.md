## 一、移动端串口收敛（老板提出：手机端连不上串口，只支持网口/蓝牙）

**背景**：手机/平板浏览器（Android WebView、移动 Chrome/Safari）没有 Web Serial API，串口直驱（电子秤读重、钱箱直连、小票机串口）在手机上本来就是死路。

**改动（PWA）**：
- `app.js` 设备管理按「电脑端 pcSerial = navigator.serial 且非移动 UA」分流：
  - 手机端：电子秤行 → 「手输重量」状态（无连接按钮）；钱箱行 → 「网口弹箱」按钮（走网口小票机转发，见下）；串口小票机行整行隐藏，仅保留「网口小票机 · 测试打印」。
  - 电脑端：三行串口连接入口原样保留。
  - 提示文案分手机/桌面两种，说明网口配置路径（后台打印中心 IP:9100）。
- `printers.js`：
  - `directPrint()` 串口分支在移动 UA 下直接拒绝并提示改用网口小票机，回落浏览器打印。
  - 新增 `kickDrawer()`：ESC p 弹箱指令经默认**网口小票机**转发（钱箱 RJ11 接打印机上）——手机端钱箱的正解。
  - 蓝牙：浏览器无稳定蓝牙打印通道（Web BLE 机型碎片化），本期不接；蓝牙机型可先走系统配对+浏览器打印兜底，待后续按机型评估。

## 二、P4 模版编辑器（三类编辑器收敛 + 导入导出 + 预置恢复）

**后端**：
- `BIZ_TYPES` 扩 `pricetag`（价签）/ `scale`（秤贴）/ 补 `order`（订货单，修复 V4.15.7 订货单 A5 留痕被 40003 静默吞掉的漏配）；`FIELD_POOL` 对应三组字段池。
- 标签渲染内核 `print.label.ts` 全链路接模版：`LabelCfg{fields}` + `mkHas()`，TSPL/ZPL 的价签（品名/售价/促销价/条码/单位/规格/保质期）与秤贴（品名/单价/重量/金额/条码/时间）逐字段显隐；`POST /printers/:id/labels` 支持 `templateId`，缺省按 jobType 取默认标签模板（秤贴→scale，其余→pricetag）。
- 新端点 `GET /print-templates/default?bizType=&kind=`（仅登录）：默认模版下发（PWA 收银小票、docprint A5 都吃这份配置）。
- 新端点 `POST /print-templates/restore-presets`（print.template 权限）：缺失预置一键补回，改过的不动。
- `renderTemplatePreview` 样例补价签/秤贴字段。
- 迁移 069：预置「标准价签」「标准秤贴」标签模板（每店一份默认）。

**前端（打印中心 · 模板 Tab）**：
- 字段芯片加 ▲▼ 上/下移（先同步勾选态再交换，防重渲染丢勾选）。
- 标签类模板隐藏 二维码/广告/切刀/钱箱 选项行（不适用）。
- 导出（下载 JSON 备份/跨店共享）/ 导入（JSON 覆盖当前模板，含结构校验）。
- 「恢复预置」按钮一键补回缺失预置模板。

**渲染消费（模版真正生效）**：
- PWA 收银小票 `buildReceiptBytes`：`GET /print-templates/default?bizType=receipt`（60s 缓存）→ 模版 title 作店名抬头、orderNo/time/cashier/member/discount(抹零)/items/pay/thanks 逐字段显隐、options.cut=false 关切刀；无模版=全显示向后兼容。
- A5 `docprint.js`：默认 A5 模版 → 抬头标题覆盖、备注字段显隐、默认联数预填打印弹窗。

## 三、P5 多联 / 重打 / 打印历史

- **小票存根联**：`pos.print.copies=2` 时第二联自动切「存根联」版式——`- - 存 根 联 - -` 标头 + **大写金额**（新增 rmbCapital）+ 收银员/顾客签字区；网络与串口通道同口径。
- **A5 联次**：份数语义改「联」——2 联起第一联「存根联（自留）」、后续「客户联（按需分发）」，单联印「正本」；重打时页眉红字 `*** 重打 ***`。
- **重打标识**：PWA 小票 jobType=重打 印 `** 重 打 **`（既有）；A5 重打标识 + 留痕 content 追加「· 重打」。
- **留痕增强（迁移 069）**：print_jobs 加 `biz_no`（业务单号）/`biz_id`（单据 id）列 + 索引；`POST /print-jobs/a5` 落 bizId；历史行带单号。
- **打印历史升级**：业务类型 / 打印类型（打印/测试页/A5打印/价签/秤贴/弹箱）/ 状态 / 单号·内容搜索 四维筛选；A5 行（有 biz_id 且有 docs.print.a5 权限）出「重打」按钮——直接按单据 id 重取数调起浏览器打印并留痕重打标识。
