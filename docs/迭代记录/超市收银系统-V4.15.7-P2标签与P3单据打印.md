### 1.2 后端 `print.label.ts`（新建，指令内核）
- **TSPL**（汉印/佳博/TSC/通用）：GBK 编码 + TSS24.BF2 中文字库；`SIZE/GAP/DIRECTION/CLS/PRINT`，块文本 BLOCK 自动折行，BARCODE CODE128，原价划线用 `LINE` 压线
- **ZPL**（斑马）：`^CI28` UTF-8；`^A0N/^FB/^BY2,2,80^BCN/^GB` 划线；`^PQ` 份数
- **纸型**：8 dots/mm，40x30→320x240、50x30→400x240、60x40→480x320
- **价签版式**：品名两行 → 价格行（促销价放大 + 原价划线）→ 单位·规格·保质期（keepDays≤90 天 / >90 折月）→ CODE128 条码
- **秤贴版式**：品名 + 称重时间 → 单价/重量 → 金额放大 → 条码
- `buildLabelBytes(lang, items, w, h)`：按品份数 `PRINT 1,n` / `^PQn`

### 1.3 后端 `device.module.ts`
- 打印机建档/编辑：`printerType`（小票/标签）+ `labelSize`；标签机 width_mm 自动取纸型宽，小票机仍限 58/80
- `GET /printers/brands` 增加 `printerTypes`/`labelSizes`
- **`POST /printers/price-tags`**：按商品 id 批量出打印字段（零售价 + 进行中促销价：特价 specialPrice / 定时打折时间窗 rate，同层取更低价；scope 命中复用 promotions 同规则）
- **`POST /printers/:id/labels`**：价签批量/秤贴。品牌自动选内核（斑马=ZPL，其余=TSPL）；网口=服务端直发 + print_jobs 留痕 + 设备状态；串口=留痕 + 返回 dataBase64 由浏览器 WebSerial 发送；小票机打标签 → 40003 拒绝；USB/蓝牙 → 提示走系统驱动
- `POST /printers/:id/test`：标签机网口测试页发标签测试字节（TSPL/ZPL 按品牌）

### 1.4 前端
- **打印中心 `print.js`**：打印机弹窗加「设备类型」（小票机/标签机，联动切换纸宽/纸型）；列表加类型列，纸宽列按类型显示纸型
- **商品档案 `products.js`**：勾选商品 →「🏷 价签打印」按钮（与删除按钮联动显隐）→ 弹窗选标签机/每品份数 → price-tags 拉数据（促销价预览）→ labels 打印；串口返回 base64 时 **WebSerial 直发**（新共享 `serialprint.js`，requestPort 在点击手势内，115200 波特率）
- **PWA 收银 `checkout.js`**：称重行加「🏷」按钮 = 即时秤贴（重量取行 qty，读重/手输均可）；网口标签机直发，串口标签机提示改网口；**SW 升 v36**

## 二、P3 A5 业务单据（七类版式 + 三入口 + 权限 + 份数）

### 2.1 统一模块 `frontend-web/docprint.js`（新建）
- **七类取数归一化**：inbound `/purchase/inbounds/:id`、return `/purchase/returns/:id`、order `/purchase/orders/:id`、loss `/inventory/losses/:id`、count `/inventory/counts/:id`、transfer `/inventory/transfers/:id`、recon `/purchase/recons/:id`（对账单 = 账期流水式：单号/日期/金额/未付，合计=应付）
- **A5 版式**：CSS `@page A5 portrait`，一单一页；抬头 + 单号/供应商/状态/制单人 + 明细表格（合计行落数量列与金额列，对账单整行落应付）+ 签字区（操作员/审批人电子签字图随单打印）+ 「第 X 份/共 Y 份」
- **份数 1~3**：每份独立分页；**批量**：多张单据顺序拼接一次打印
- **留痕**：打印调起后逐单 `POST /print-jobs/a5`（RequirePerms docs.print.a5；bizType/bizNo/copies → print_jobs，job_type='A5打印'）
- `canPrintA5()` 权限判断 + `autoA5Enabled()` 读取设置（jsonb 值 0/1 兼容）

### 2.2 三入口接线
| 入口 | screens | 说明 |
|---|---|---|
| 详情打印 | purchase（入库）、returns（退货）、po（订货）、ops（盘点/调拨）、报损详情弹窗 | 「🖨 打印单据 A5」→ 弹窗选份数；无权限 toast 提示 |
| 列表勾选批量 | purchase、returns、po、ops 三列表 | 新增打印勾选列 + 「🖨 打印所选(n)」按钮（与删除勾选互不干扰，独立 Set） |
| 审核后自动弹 | 入库审核、退货单张/批量审核、订货审批签名、报损/盘点审核、调拨确认 | `doc.print.auto_a5` 开启且有权限时 `autoPrintA5AfterAudit` |

- 旧 purchase.js/returns.js/po.js 三处本地 printDoc/printInbound/printReturn/printPo 移除，收敛到 docprint.js（recon.js 的 A5 结算单原有版式保留不动）
