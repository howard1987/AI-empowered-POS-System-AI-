## 一、支付通道遗留收口

### 1. 微信平台证书验签（fail-closed）
- `/v3/certificates` 拉平台证书 → APIv3 密钥 AES-256-GCM 解密 → 内存缓存 serial→PEM（12h TTL，未知序列号强制刷新一次）
- **所有 200 应答（扣款/退款/查单）强制验签**：`Wechatpay-Timestamp/Nonce/Signature/Serial` 四头 + 原始应答体，SHA256withRSA 平台证书公钥；**验签失败拒绝信任该应答**（防中间人伪造「支付成功」）；4xx 错误应答有签名头也验
- 从「直连 HTTPS 就信」升级为「签名不合法宁可拒绝」，与支付宝侧应答验签对齐

### 2. USERPAYING 查单轮询（顾客输密中不再被误判失败）
- 扣款返回 USERPAYING → 落 `pay_gateway_txns` **PENDING** 行 → 按设置轮询查单：`pay.gateway.userpaying_polls`（默认 8）× `pay.gateway.userpaying_interval_sec`（默认 4s）
- SUCCESS → 迁移成功直接落单；CLOSED/REVOKED/PAYERROR/NOT_PAY → FAIL 透出；用尽次数 → 保留 PENDING 返回 `pending:true`
- PWA 收银台转「等待顾客确认支付」+ 3s 查单兜底（`GET /pay/txn/:no`，后端对 PENDING 行自动向通道补查），全程提示**勿重复扫码**

### 3. 开钱箱 + 小票钩子（`pwa/receipt.js` → `window.PwaReceipt`）
- 落单成功（非应急单）自动打印 **58/80mm 销售小票**：隐藏 iframe + `@page size`，浏览器打印通道无驱动依赖；明细/合计/支付方式/会员/抹零/单号尾号，成功条内可**补打**
- 现金收款再发 **ESC/POS 弹箱指令**（WebSerial，`ESC p 0 25 250`）；收银台新增「💵 连接钱箱」按钮（用户手势内授权，与连秤同款交互）
- 设置项：`pos.receipt.auto_print`（默认开）/ `pos.receipt.width`（58/80）/ `pos.drawer.enabled`（默认关）；硬件异常只提示不阻断收银

## 二、系统设置可用性整改（一句话：设置要看得懂、易于设置）

### 1. 分组归并 17 → 6
| 新分组 | 吸收原分组 | 项数 |
|---|---|---|
| AI赋能 | AI · AI 引擎 · AI与设备 · 智能能力 | 52 |
| 商品管理 | 商品与库存 · 采购与供应商 | 14 |
| 财务管理 | 分红与会员 · 会员 | 15 |
| 营销与线上 | 促销营销 · 营销 · 线上渠道 | 18 |
| 支付 | 独立保留（通道配置敏感） | 15 |
| 通用设置 | 收银 · 收银与小票 · 门店与运维 · 权限与安全 · 销售 | 22 |

只改 group_name，键/值/默认值全保留；boss 端能力开关页改按键名前缀过滤（不再依赖分组名）。

### 2. 枚举项全部「下拉 + 中文说明」（替代「取优/叠加（可选：取优/叠加）」）
`enum_options` 落 `[{v,label}]`：抹零规则（不抹零/抹到角/抹到5角/抹到元）、优惠叠加（取优=只给最大优惠/叠加=多层同享）、分红上限口径（A 离散/B 连续）、大额确认方式（现场补签/短信确认）、识别引擎（VL 大模型/模拟/YOLO 预留）、支付通道模式（记账式/模拟/真实）、小票纸宽（58/80）。现值校验仍在选项内，不丢值。

### 3. JSON 项结构化编辑器
- `stock.expiry_warn_days`「[7,3]」→ 「临期 __ 天前 + 临期 __ 天前」输入框
- `promo.expiry_auto_discount` → 档位行：临期 ≤ __ 天 → 按 __% 原价销售（加档/删档/保存）
- `auth.sign_required_scenes` → 入库单/退供单/报损单/对账单/盘点单 复选框
- `ops.emergency_pay` → 角色 复选框（预设店长/收银员/收银主管/库存管理员）
- `ai.fraud_baseline` / `ai.assoc_rules` → **只读**展示（系统自动维护，不让用户碰 JSON）
- 其余 JSON 兜底 pretty 文本域（Ctrl+Enter 保存）

### 4. 变更留痕每页 10 条翻页
`GET /settings/changes?page&pageSize`（默认 10，兼容旧 limit）返回 `{rows,total,page,pages}`；前端上一页/下一页 + 「第 X/Y 页 · 共 N 条」。

### 5. 密钥防呆补强
占位文案「未配置」提交与掩码回显一样按「不修改」处理（防把字面量当新密钥加密落库）。
