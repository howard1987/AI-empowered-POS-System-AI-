# 超市收银系统 V4.25.5 — 改价/折扣需店长现场授权（授权码）

> 来源：老板需求（2026-09-13）
> 「收银员改价/打折时，需要弹窗登录店长权限（**仅授权用，非全权登录收银端**）。比如 A 商品售价 5 元、最低售价 3 元，店员需要改价 4 元，当收银员操作改价时，弹出弹窗，**店长账号 + 授权码（单独设置，与账号密码分开）**。」

---

## 一、两层控制（先分清）

| 层 | 触发条件 | 凭据 | 作用 |
|----|----------|------|------|
| **① 现场授权（本版新增）** | **任何**改价 / 单品折扣 / 赠品 / 整单折扣 | 店长**工号 + 授权码** | 授权本次价格操作；**不切换收银员登录身份** |
| ② 越线放行（既有） | 折后价低于最低卖价线或进价 | 权限点 `pos.emergency.manual` | 允许突破价格红线并留痕 |

老板的例子（售价 5、最低 3、改价 4）：**未越线**，但仍需 ① 店长授权码。

---

## 二、授权码（与登录密码分开）

- 存 `employees.auth_code_hash`（bcrypt），**独立于登录密码与 PIN**；要求 4~8 位数字，且不得与登录 PIN 相同。
- **设置入口**：收银端「设置 → 店长授权码 → 设置/修改」（仅持 `pos.price.authorize` 权限者可见）；设置/清除均需**输入本人登录密码**确认。
- 连续错 5 次锁 5 分钟（防试猜）；接口另有 IP 频控。

**谁有资格授权**：持 `pos.price.authorize` 权限点的员工。迁移 096 已**自动绑给所有原本持有 `pos.emergency.manual`（店长放行权）的角色**，以及「超级管理员」角色 —— 无需手工配权限。

---

## 三、授权流程（收银台）

1. 收银员点「改价 / 折 / 赠 / 整单折扣」并确认 → 若当前**无有效授权票据**，弹出「🔐 店长授权」框：
   - 店长工号 + 店长授权码（回车即提交）
   - 弹窗明确提示「仅授权本次价格操作，不会切换当前收银员身份」
2. 验证通过 → 服务端签发 **120 秒短时票据**（JWT，`scope=price`）。
3. 该票据随下单提交（`priceAuthTicket`）；**票据在结算完成后作废**（下一单改价需重新授权）。
   - 同一单内多行改价/打折共用一次授权，避免反复输码。
4. 服务端 `POST /sales/checkout` 强制校验：含改价/折扣/赠品的单**必须携带有效票据**，否则拒绝。

**留痕**：① 授权事件 `audit_logs.action = auth.price_authorize`（授权人 + 时间）；② 下单时 `价格操作授权留痕`（操作人 + 授权人 + 涉及行）。

## 四、错误码

| 码 | 含义 |
|----|------|
| 41020 | 工号不存在或已离职 |
| 41021 | 该工号未设置授权码（提示先到设置页设置） |
| 41022 | 该工号无改价/折扣授权资格（需店长级权限） |
| 41023 | 授权码不正确 |
| 42901 | 授权码连续错误已锁定（5 分钟） |
| **50035** | 下单含价格操作但**未携带授权票据**（提示现场授权） |
| **50036** | 授权票据**过期或无效**（有效期 120 秒，需重新授权） |

## 六、待你确认的两点

1. **授权复用**：当前为「一次授权 120 秒内可连续改价/打折，**结算后作废**」。若你要求**每次点改价都弹窗输码**（哪怕同一单），告诉我，我改成单次票据。
2. **谁必须输码**：当前**所有人（含店长本人）**操作改价都需授权码（责任到人，防冒用登录态）。若希望「店长本人登录时免输」，也可以调整。

---

## 七、你在真实环境要做的

1. 收银台 **Ctrl+F5** 确认版本号 = **V4.25.5**（缓存 `pwa-shell-v70`）。
2. **店长登录收银台** → 设置 → **店长授权码** → 设置（需登录密码确认）。
3. 收银员账号改价/打折 → 应弹「店长授权」框；输入店长工号 + 授权码后放行。
4. 未设授权码的店长无法授权，会明确提示去设置。
