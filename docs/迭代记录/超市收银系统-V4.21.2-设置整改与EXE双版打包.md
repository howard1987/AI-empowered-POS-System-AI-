# 超市收银系统 V4.21.2 版本说明
## 主题：系统设置整改（设备管理分组 + 选项人性化）+ 收银台 EXE 双版打包

日期：2026-09-11 　前置：V4.21.1（局域网接入 + 收银机授权 + 收银端保存加固）

---

## 一、背景（老板反馈两项）

1. **系统设置看不懂**：Web 后台「收银台」「收银」两组碎片化；新版收银台开关/库存硬拦/重复扫防抖显示 1/0；整单折扣预设规则、客显空闲轮播、收银快捷键映射裸 JSON；播报音色/语速是空文本框无选项；「收银」组有授权开关但无设备列表，开关切换像"无法保存"。
2. **要收银台 EXE 安装包**：Windows 11 与 Windows 7 两版。

## 二、设置整改（迁移 091 + Web 后台 settings.js + 收银端 cashier.js）

### 2.1 迁移 `091_v4212_settings_device_group.sql`（幂等）
| 项目 | 改造前 | 改造后 |
|---|---|---|
| 分组 | 收银台（20 项）+ 收银（pos.device.auth） | **合并为「设备管理」**（25 项） |
| 新版收银台开关 | number 1/0 | **bool**（开/关拨杆） |
| 库存硬拦 | number 0/1 | **enum 是/否**（是=超库存一律拒绝 / 否=容许负库存+留痕） |
| 锁屏闲置超时 | 默认 5 分钟 | **默认 15 分钟**（门店显式改过的不动；仅未改过的 5 → 15） |
| 重复扫防抖 | number 1/0 | **bool 开/关**（开=同码 2 秒内连扫不重复加件，逻辑不变） |

### 2.2 Web 后台 `frontend-web/screens/settings.js`
- **结构化编辑器**（JSON_EDITORS，替换裸 JSON）：
  - `pos.discount.presets` 整单折扣预设：折扣名 + 打 X 折 行编辑，加一档/删档/保存；
  - `display.ads` 客显空闲轮播：图标 + 主标题 + 副标题 行编辑；
  - `pos.cashier.hotkey_map` 收银快捷键映射：收款/挂单/取单/重复上一单/打印/锁屏 六键下拉（F1~F12；冲突互换仍在收银台设置面板做）。
- **播报音色/语速下拉**：`pos.cashier.tts.voice` 复用本机 speechSynthesis 中文音色枚举 + 🔊 试听（与老板端 voice.tts.voice 同款，试听改行内取下拉，两行共存）；`pos.cashier.tts.rate` → 跟随老板端/0.85/1/1.1/1.25 下拉。
- **收银机授权设备列表卡**（「设备管理」页签独显）：GET /pos-devices 表格（待授权排前），✓通过（可同时命名）/停用/启用/命名/删除；空态提示开授权开关后自动登记。浏览器拿不到 MAC，采用设备码+浏览器指纹白名单（强于 MAC 绑定）。
- **保存失败必须明示**：save() catch 由静默回退改为 toast「保存失败：原因」（消除"开关设置后无法保存"的错觉；实测开关往返保存正常）。

### 2.3 收银端 `pwa/cashier.js`
- loadSettings 分组改读「设备管理」（旧组名兜底一次，防迁移未跑）；
- debounce/stock_hard 兼容 bool 与旧 1/0；new_ui 直落判断兼容 bool false（原实现会把 false 误判为开）；锁屏默认 5→15；设置面板防抖保存改布尔。

### 2.4 Web 后台登录补设备码（`frontend-web/app.js`）
- 登录请求携带 `deviceCode`（localStorage 持久化 `D+8HEX`）——设备授权开启后，非超管员工在 Web 后台登录也不会被 40307 卡住。

## 三、收银台 EXE 双版打包（frontend-desktop）

- 版本号 0.1.0 → **4.21.2**（产物文件名带版本）；两份 electron-builder 配置移除 electron-builder 25 不接受的 `_comment` 键。
- **Win11/现代轨**（`dist:modern`，Electron 44.3.0 / x64）：portable + NSIS 安装包；
- **Win7 冻结轨**（`dist:win7`，Electron 22.3.27 / ia32）：portable + NSIS 安装包（Electron 22 是支持 Win7 的最后一大版本）。
- 两轨源码完全共享（src/main.js + preload.js）；EXE 默认 `ui:'pwa'` 加载 `desktop-config.json` 里配置的 server（默认 http://127.0.0.1:3100，可配 POS_SERVER 环境变量），副屏自动加载客显页；F 键全局热键经 IPC 重注册；静默打印走 pos:print-html。
