# 超市收银系统 V4.18.3 版本说明 —— 收银业务深度 P15 批2（积分抵现/会员挂账销账/整单折扣）

> 发布日期：2026-09-11　|　前置版本：V4.18.2　|　迁移：084_v4183_p15_funds.sql　|　SW：pwa-shell-v48

## 一、本版范围（P15 批2 · 设计文档 §13.1/§13.2 定稿落地）

| 功能 | 决策口径 | 落地 |
|---|---|---|
| 整单折扣 | 后台预定义命名规则套用免权限；自定义折扣率需 `pos.discount.custom` 权限+留痕；不得突破最低售价 | ✅ |
| 积分抵现 | 比例可设（`pos.points.rate` N 分=1 元）+ 单笔上限（`pos.points.max_pct` %应收）；结算页操作，抵扣流水留痕 | ✅ |
| 会员挂账 | 结算页「会员挂账」通道（赊账），限额 `pos.credit.limit` 超限需 `pos.credit.over` 放行；账期 `pos.credit.due_days`；销账默认最旧优先可自选、支持部分销账 | ✅ |
| 挂账销账 | 「挂账/还款」弹窗：欠款列表/合计/超期标记 + 收款销账（现金/微信/支付宝/余额）+ 结清最旧快捷；逐笔 `credit_pays` 留痕 | ✅ |
| 关闭/核销 | 限 `pos.credit.close` 权限（店长）+ 必填原因留痕；核销补 0 元流水记录坏账 | ✅ |

## 二、后端改动

1. **迁移 084**：`sales_orders.order_discount` 列；设置 `pos.discount.presets`（预设折扣规则 jsonb，默认 员工折扣95/会员日90）；权限点 `pos.discount.custom` / `pos.credit.over` / `pos.credit.close`。
2. **sales.module.ts checkout**：
   - 整单折扣（1.7c 段）：促销/券后、抹零前冲减；折数非预设规则→要求 `pos.discount.custom`；**逐行校验折后单价 ≥ min_price**（防绕过行级改价红线）；原因必填；audit 留痕。
   - 积分抵现：比例优先 `pos.points.rate`（回落 `points.redeem_rate`）；累计抵扣 ≤ 应收×max_pct，超出 50034；照旧 `points_flows` 流水。
   - 赊账通道：必须选会员；单笔超 `pos.credit.limit` 需 `pos.credit.over`（ADMIN `*` 直通）；计有效消费；落单后建 `member_credits`（到期=CURRENT_DATE+due_days）。
3. **pos.module.ts 新端点**：
   - `GET /pos/credits?memberId=` 在途欠款（未结/部分结清，最旧优先+超期标记+合计）
   - `POST /pos/credits/settle` 销账：默认最旧优先分摊 / `allocations` 自选（合计必须相等）；部分销账 partial；事务 FOR UPDATE；audit
   - `POST /pos/credits/:id/close` 关闭/核销（`pos.credit.close`，原因必填）

## 三、前端改动（cashier.js）

- 结算弹窗（F9）：新增**会员挂账**支付页签（在线+已选会员可用）；整单折扣位（预设按钮+自定义+取消）；积分抵现位（可用积分/上限弹窗/清除）；会员挂账位（挂账/还款入口）。
- 合计区分层（A1）：商品总额→会员价已省→券→**整单折扣**→促销→**积分抵现**→抹零→应收。
- calc() 折扣/积分进应收口径与服务端一致；落单后折扣/积分自动重置；支付数组主通道在前（小票/播报口径）。
- 会员卡新增「挂账/还款」按钮 → openCreditsModal（欠款列表/收款销账/结清最旧/店长关闭核销）。
