## 一、会员掌上 H5（backend/public/member/index.html，新）

单文件应用（HTML+CSS+JS，零依赖、零构建），复用 PWA 设计语言（米色纸感 + 深绿主色 + 同套 CSS 变量），移动端优先（≤520px 居中、safe-area 适配）。访问：`https://<门店地址>:3443/member/`（同源，HTTPS 保证扫码安全上下文）。

- 注册成功/下单成功/自助结算成功三个 Aha 时刻分别突出 卡号/自提码/离场核销码
- 充值、离场核销、分红口径均配一句「人话」说明条（延续设置页人话化原则）

## 二、开业初始化一键执行（frontend-web/screens/settings.js）

- 系统设置页底部新卡「🏗️ 开业初始化」：**仅持 `sys.data.backup` 权限（或超管）可见**，其余角色不渲染
- 预览即所见：`GET /admin/reset/preview` 分组展示各清空组实时行数（交易与结算/库存与单据/会员与分红/供应商往来/AI 数据/操作日志）+ 基础档案 + 设备模板 + **始终保留清单**
- 两层防误触：① 模式单选（默认「保留基础档案」，可选「出厂全清」）+「同时清空设备模板」勾选；② 必须手动输入「初始化」→ 提交前再弹红色 confirmBox 最终确认
- 执行 `POST /admin/reset/execute {mode, clearDevices, confirm:'初始化'}`（服务端白名单拼表，客户端传不了表名）；完成后自动刷新预览行数
- 实测：preview 返回 8 分组（257/196/11/0/62/1210/252/17 行 + 保留 8 表）
