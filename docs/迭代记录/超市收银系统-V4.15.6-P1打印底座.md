# 超市收银系统 V4.15.6 —— P1 打印底座（指令级直驱 + 品牌通用适配 + 收银自动打印）

## 一、关键发现与架构决策

实施前盘点发现系统已有完整打印底座（设计文档 9.9 打印中心）：
- `printers` 表：多机并存/默认机唯一/纸宽 58|80
- `print_templates` 表：字段池显隐（小票 + A5 七类单据）/联次/预览引擎 `print.render.ts`
- `print_jobs` 表：打印历史（打印机/模板/操作人/耗时）
- Web 后台 `print.js`：打印机管理 + 模板编辑器 + 历史三个 Tab

**决策：复用既有底座，只补四个真实缺口**（放弃了另建 print_devices/print_logs 表的原方案，迁移 067 修订为纯增量）：
1. 网口打印机此前只探测可达性、从不发指令 → 补真发通道
2. 无 ESC/POS 指令级直驱（PWA 只有浏览器 iframe 打印）→ 补内核
3. 无收银结账自动打印接线（收银端开关）→ 补设置+调用
4. 无品牌维度 → 补品牌通用适配

## 二、落地明细

### 2.1 迁移 067（`067_v4156_print_foundation.sql`，幂等）
- 清理误建 print_devices；`printers ADD COLUMN brand VARCHAR(32) DEFAULT '通用'`
- `printers_conn_type_check` 约束扩展 +`'串口'`（WebSerial 直驱，免系统驱动）
- 设置种子（收银组，enum 下拉）：`pos.print.auto` 结账自动打印小票（默认开）/ `pos.print.copies` 小票联数 1~2

### 2.2 后端 `device.module.ts`
- `PRINTER_CONNS += 串口`；`PRINTER_BRANDS = [芯烨, 佳博, 得力, 爱普生, 汉印, TSC, 斑马, 通用]`
- 新增 `GET /printers/brands`（前端下拉数据源）
- 新增 `POST /printers/:id/send`：**网口真发**（net socket 直写 ESC/POS 字节到 IP:9100，成功/失败均落 print_jobs 并更新设备状态）；**串口留痕**（字节由浏览器 WebSerial 发出，dataBase64 可空，仅记录历史）
- `POST /printers/:id/test` 升级：网口机型用 iconv-lite GBK 编码真发测试页字节（含切刀指令），失败记「失败」历史+设备置故障
- 串口机型创建时连接地址允许留空

### 2.3 PWA 新增 `printers.js`（`window.PwaPrinters`）
- **GBK 编码**：`TextDecoder('gbk')` 反查表动态构建（约 2.4 万映射，懒加载一次 <50ms，无外部依赖）——中文热敏机标准字符集
- **ESC/POS 构建器**：init/对齐/倍高宽（GS !）/切刀（GS V B）；58mm=32 列、80mm=48 列版式（店名倍高居中、明细名左金额右、合计倍高、脚注+切刀），重打自动加「\*\* 重 打 \*\*」标识
- **三级通道**：`autoPrint(snap)` = pos.print.auto 总开关 → 直驱（串口 WebSerial / 网口代理，按联数重复发送）→ 浏览器 iframe 打印兜底（PwaReceipt）；`reprint` 强制直驱优先并留「重打」痕迹
- 默认打印机缓存 60s；串口连接/断开/状态；`testDirect` 设备管理真发测试

### 2.4 收银接线 `checkout.js`
- 结账成功：`PwaPrinters.autoPrint(snap)` 取代原 `PwaReceipt.printReceipt`（后者降级为兜底通道）；现金收款弹钱箱逻辑不变
- 「补打小票」：`PwaPrinters.reprint(snap)`，重打标识+留痕

### 2.5 移动端「我的-设备管理」`app.js`
- 小票机：连接（WebSerial 授权）→ 状态「串口直驱」→ 按钮变「测试打印」（真发测试小票）
- 新增「网口小票机」行：一键真发测试（后台打印中心配置 IP:9100 并设默认后可用）

### 2.6 Web 后台 `print.js`（打印中心）
- 新增/编辑打印机弹窗加**品牌下拉**（8 家）；连接方式加「串口」；网口地址格式前端校验（IP:port）
- 打印机列表加品牌列；表头注明「网口/串口指令直驱 · USB/蓝牙走系统驱动」
