# 超市收银系统 V4.20.0 版本说明
## P16 批1 · EXE 部署形态收口（2026-09-11）

> 部署形态定稿（§13.12）：PC 收银机走 EXE 安装包（基于 V4.8.x Electron 端演进），手机/平板走 PWA。本批把新收银台（PWA）与 EXE 壳打通，并搬运打印静默通道。

---

## 一、EXE 壳新能力（frontend-desktop）

| 能力 | 落地 |
|---|---|
| 新收银台模式 | `src/main.js`：`desktop-config.json`（userData 目录，`{"ui":"pwa","server":"http://127.0.0.1:3100"}`）或环境变量 `POS_UI=pwa` / `POS_SERVER=...` → 主屏加载后端 PWA 收银台（`?desktop=1` 标记）；缺省沿用本机旧 UI，双轨共存 |
| 全局快捷键 | `globalShortcut` 注册 **F2挂单 / F4取单 / F6重复上一单 / F7打印开关 / F8锁屏 / F9结算** → `sendInputEvent` 转发到主屏页面（浏览器收银台同键位，EXE 内全局生效）；退出时注销 |
| 静默打印通道 | 新 IPC `pos:print-html`（隐藏窗口 `webContents.print({silent:true})`，按 58/80mm 设微米页宽+窄边距）——**真静默，无预览弹窗**，根治浏览器通道弹打印预览的问题 |
| 串口权限 | permission handler 放行 `serial`（WebSerial 钱箱/串口小票机在 EXE 内与 PWA 同链路），usb/media 沿用 |

## 二、PWA 侧适配

- `preload.js` 暴露 `window.DesktopShell = { isDesktop, silentPrintHtml(html,{widthMm}) }`。
- `receipt.js` printReceipt：检测 `DesktopShell.silentPrintHtml` → EXE 端走 Electron 静默打印（hiprint v3 版式 HTML 同样适用），失败回落 iframe；浏览器端行为不变。
- `cashier.js` csPrintHtml（交接班单/营业日报）：同上接 EXE 静默通道。

## 三、使用方式

1. 装 EXE（`npm run dist:modern` 出 x64 安装包；Win7 老机 `dist:win7`）。
2. 收银机放一份配置：`%APPDATA%/超市收银系统/desktop-config.json`：
   ```json
   { "ui": "pwa", "server": "http://192.168.x.x:3100" }
   ```
3. 启动即全屏进入新收银台；小票经「默认小票机」（网口/USB 系统驱动 RAW/串口）静默直出，无任何预览弹窗。
