# 超市收银系统 V4.18.4 — 收银业务深度 P15 批3（交接班 / 钱箱过程管理 / 日结 / 跨零点）

> 发布日期：2026-09-11　|　迁移：085　|　SW：pwa-shell-v49　|　前置基线：V4.18.3（P15 批2）

## 一、本版范围（设计文档 §13 B3/B4/E1 定稿口径）

| 能力 | 说明 |
| --- | --- |
| 交接班增强 | 班次汇总加挂账/积分渠道；**应答金额 = 备用金 + 现金收入 − 现金退款 ± 钱箱存取**；实点 vs 应答差异留档；**超容差强制填原因**（`pos.shift.diff_tolerance`，0=不容差） |
| 钱箱过程管理 | 开班备用金写入流水（口径起点）；班中存入/取出**必选原因**（换零/取现/备用金补充/对账调整）留痕；交接班应答闭环 |
| 无交易开钱箱 | 对钱/放零场景：`pos.cashbox.open` 权限 + 留痕；**弹箱失败自动留痕**（E1：收现弹箱失败也记） |
| 日结 | 独立于交接班的「日汇总」——结店不结人：分渠道流水/退货/抹零/整单折扣/成本毛利/负库存笔数 + 本日班次一览，可打印日报 |
| 跨零点日切 | 收银中跨零点自动提示（分钟级监测）；**归属口径 B4：班次按支付完成时间、按开班时间计班；日结按自然日** |

## 二、后端改动

### 迁移 085（`db/085_v4184_p15_batch3.sql`，幂等）
- `shifts` 加列 `close_reason VARCHAR(200)`（超容差差异原因留档）
- 权限点 `pos.cashbox.open` 无交易开钱箱（risk 1，模块沿用 shift.manage 同组）

### `shift.module.ts`
- `summary()`：渠道聚合加 **赊账 creditSales / 积分抵扣 pointsSales**；聚合 `cashbox_flows` 存入/取出；返回 `openingFloat / cashboxIn / cashboxOut / cashboxFlows / cashboxTotal`（应答金额）
- `open`：备用金 >0 时同步写一条「备用金」钱箱流水
- `close`：应答口径改为 `cashboxTotal`；`|diff| > pos.shift.diff_tolerance` 且未填原因 → **50061 拒绝**；原因落 `close_reason` 并入 audit
- 新端点：
  - `GET /shifts/cashbox` 本班钱箱流水（近 200 条，含操作人）
  - `POST /shifts/cashbox` `{type:'存入'|'取出', amount>0, reason∈固定四项}`（40003 逐项校验）
  - `POST /shifts/open-drawer` 无交易开箱留痕（`pos.cashbox.open`；`{reason, failed}`，弹箱失败也调）

### `pos.module.ts`
- `GET /pos/daily?date=YYYY-MM-DD`（缺省今天）：分渠道流水（`pay_paid_at::date` 归属=B4 支付完成口径）、总额段（商品/促销/券/整单折扣/抹零/应收/成本/毛利）、退款（自然日 `sale_refunds.created_at`）、**负库存笔数**（audit_logs `module='收银' AND action='负库存售卖'`）、本日班次列表

## 三、前端改动（`cashier.js`）

- 顶栏新「**班次**」按钮：无班次=开班弹窗（备用金默认 `pos.cashbox.float_default` 可改 + 不开班也可查日结）；有班次=显示「班中 h:mm」绿点
- **班次面板**：班次信息 + 分渠道实时汇总 + **应答金额大字展示** + 钱箱流水（近 8 条）+ 存入/取出（原因下拉必选）+ 交班 / 日结 / 开钱箱
- **交班弹窗**：应答金额、实点输入、**差异实时计算**（超容差变红 + 原因输入框自动出现）、确认后打印交接单（分渠道明细 + 应答/实点/差异 + 原因 + 签字区）
- **日结弹窗**：日期选择（默认今天）→ 汇总 + 渠道明细 + 负库存警示 + 本日班次；「打印日报」58/80mm 版式
- **跨零点提示**：`startDayTick()` 分钟级监测日期变化，toast 提示班次/日结口径
- **E1 弹箱失败留痕**：doCheckout 现金弹箱 catch 分支自动调 `/shifts/open-drawer {failed:true}`
- 新增 `csPrintHtml()`：交接单/日报专用 58/80mm 自包含 iframe 打印（不走小票模版）
