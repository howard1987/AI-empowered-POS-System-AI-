# 超市收银系统 V4.22.2 — Windows 11 绿色版体验整改（全屏 / 登录页 / 退出 / 语音）

> 日期：2026-09-12 ｜ 关联：V4.22.1（EXE 白屏根治）、V4.21.2（双轨打包）、V4.18.7（收银台语音拟人化）
> 触发：用户用 Win11 绿色版（portable EXE）实测反馈 4 个问题
> 版本线说明：V4.23.0 是**发布工程线**（独立打包，应用版本仍 4.22.1）；本次是**应用业务修复**，应用版本 4.22.1 → **4.22.2**（严格递增）。
> 重跑 `release/build-all.ps1` 会自动读取 `frontend-desktop/package.json` 的版本 → 分发件随之变为 4.22.2。

## 一、问题（用户报障）

| # | 现象 | 影响 |
|---|------|------|
| 1 | 登录进入收银后未完全全屏，**最底下任务栏还在** | kiosk 形同虚设，顾客可点到 Windows 任务栏 |
| 2 | 登录界面铺满整屏、**没有关闭按钮** | 用户无法放弃登录；kiosk 下 Alt+F4 被拦，只能杀进程 |
| 3 | 收银退出后落到**手机移动端 PWA 界面**（底部 Tab） | 电脑端收银台被"降级"成手机工作台，回不到收银也退不出程序 |
| 4 | 语音播报音色与老板端不同、**明显机械生硬** | 播报体验差 |

## 二、根因

### 问题1：kiosk 与 fullscreen 双开关叠加

`createWindows()` 里窗口同时给了 `kiosk: KIKS` **和** `fullscreen: KIKS`。
Electron 在 Windows 上两者叠加时，`fullscreen` 语义会覆盖 kiosk 的"压住任务栏"行为（尤其 Win11 任务栏
默认置顶、或窗口失焦/分辨率变化后重排），于是任务栏偶发露出。另外窗口只按 `display.bounds` 建窗一次，
显示器缩放/热插拔后不再校正。

### 问题2：PWA 登录页是"手机优先"版式，EXE 直接复用了它

EXE 壳加载 `/pwa/?desktop=1`，但 **PWA 从未读取 `desktop=1`**（全库无该参数处理）。
登录页 `#auth` 是手机端设计：`justify-content:center` + 卡片 `padding:16px` 无最大宽度 → 在 1080p+ 上铺满整屏；
且登录页只有工号/密码/登录/忘记密码，**没有任何退出通道**——而 V4.22.1 的 EXE 是 kiosk（`close` 事件被拦截），
`pos:quit` 通道存在但 preload 未暴露、页面无人调用。

### 问题3：退出收银台走的是手机端分支

`CashierShell.exit()` 无条件 `openTab('work')` → 显示手机工作台（顶栏 + 底部 Tab）。
桌面端没有任何分支判断，于是"退出收银台"退到了手机界面。

### 问题4：EXE 环境拿不到拟真人声

实测（Electron 探针，见 §四）**EXE 内 `speechSynthesis.getVoices()` 只枚举到 3 个老式 SAPI 音色**：

```
Microsoft Huihui  - Chinese (Simplified, PRC)   ← 默认
Microsoft Kangkang- Chinese (Simplified, PRC)   ← 男声
Microsoft Yaoyao  - Chinese (Simplified, PRC)
```

老板端在 **Chrome** 里跑、收银端在 **Electron** 里跑——两者都只能拿系统 SAPI 音色；
Edge 的「晓晓 Online (Natural)」是 Edge 专有云端音色，Chrome/Electron 都拿不到。
本机注册表确认只装了老式语音（`Speech\Voices\Tokens` = Huihui/Zira；`Speech_OneCore\Voices\Tokens` = Huihui/Kangkang/Yaoyao），
**未安装 Windows 11「自然语音」包**。
叠加 `tts.js` 旧选音逻辑的缺陷：`isNatural()` 只认名字里带 `Natural|Online` 的，
Windows 11 本地自然语音（名为 `Microsoft Xiaoxiao` 等）会**被漏判**；且兜底段用 `vs.find(female)`
按数组顺序命中 **Huihui**，无法保证"挑最好听的"。

## 三、修复（V4.22.2）

### 1. 全屏加固（`frontend-desktop/src/main.js`）
- 窗口选项去掉 `fullscreen`，**只保留 `kiosk`**（二者叠加是任务栏露出的根因）
- 新增 `applyKiosk(win, display)`：`setBounds(display.bounds)` → `setKiosk(true)` → `setAlwaysOnTop(true, 'screen-saver')`
  （screen-saver 是 Electron 最高置顶层级，可压过"任务栏始终置顶"）
- 主窗/副屏建窗即应用 + `ready-to-show` 再校正一次；`leave-full-screen` → 立即回位
- `screen.on('display-metrics-changed')` → 分辨率/缩放/热插拔后重新占位
- 边界：配置向导是普通窗口，会被置顶的 kiosk 压住 → `openSetup()` 时临时 `setKiosk(false)+setAlwaysOnTop(false)`，关闭后自动恢复

### 2. 桌面端登录页（`pwa/index.html` + `pwa/app.js` + `preload.js`）
- 新增桌面端识别：`IS_DESKTOP = DesktopShell.isDesktop || /[?&]desktop=1/`，命中则给 `<html>` 加 `desktop-mode`
- 登录页桌面版式：卡片限宽 400px 居中、logo 56px、标题 20px（手机端零影响）
- 新增「**关闭程序**」按钮（`.only-desktop`，仅桌面端显示）→ `DesktopShell.quitApp()` → 主进程 `pos:quit`
- preload `DesktopShell` 补 `quitApp`（此前只有 `cashier.quitApp`，PWA 拿不到）
- 桌面端文案：标题「收银台登录」、副标题「社区超市 · 收银 / 挂单 / 交接班」+ 右下「桌面端」标记

### 3. 退出收银台（`pwa/cashier.js`）
- `exit()` 增加桌面端分支：**确认后 `logout()` → 回到桌面登录页**（登录页带「关闭程序」，需要彻底退出在那里点）；
  点"取消"则完全不动状态、留在收银台
- 浏览器/手机端分支保持原样（`openTab('work')`），零回归
- 极兜底：`logout()` 异常时退回旧路径，不白屏

### 4. 语音音色择优（`backend/public/tts.js` + `pwa/cashier.js` 设置页）
- `isNatural()` 正则扩展：`Natural|Online|Neural|Xiaoxiao|Xiaoyi|Yunxi|Yunyang|Yunxia|晓晓|晓伊|晓萱|云希|云扬|云夏`
  —— 修掉"装了 Windows 自然语音包仍被判为机械音"的漏判
- `pickVoice()` 改为**打分择优**（`score()`）：拟真 +1000 > 晓晓 +300 > 晓伊 +280 > 瑶瑶 +260 > 慧慧 +200 >
  在线谷歌 +150；男声（Kangkang/云希/云扬…）−400；在线声（断网会静默无声）−100
- `mode='local'` 时只在离线音色里挑，避免断网无声
- 新增 `PwaTTS.voiceInfo()`：当前生效音色 / 可用音色数 / 是否拟真 / 全量列表
- 收银台设置页（店长面板）：音色下拉标 ⭐ 自动择优项、标签改为「拟真/需联网/本地」、
  新增**音色诊断行**（当前生效音色 + 本机可用中文音色数 + 未检测到拟真人声告警）+ 自然语音包安装指引
- PWA 缓存版本 `pwa-shell-v60 → v61`（改动必须升版本，否则旧 SW 缓存不生效）
- 收银台版本显示 `V4.22.0 → V4.22.2`（用于肉眼确认服务器端新代码已生效）

## 六、用户待办：装 Windows 自然语音包（问题4的"变拟人"一步）

EXE/Chrome 只能用系统已装音色。要让收银端也接近真人，二选一（均离线可用、免费）：
1. **设置 → 时间和语言 → 语言和区域 → 中文(简体) → ⋯ → 语言选项 → 语音** → 安装中文语音包
2. **设置 → 辅助功能 → 讲述人 → 添加自然语音** → 选中文（晓晓/云希等）

装完重启收银端 → 收银台「设置 → 播报音色」下拉会出现带「（拟真）」的音色并自动标记 ⭐，
`isNatural` 扩展后会被自动择优选中；诊断行会从"未检测到拟真人声"变为"拟真"。
若装完 EXE 仍枚举不到（Chromium 不向 OneCore 取音色），再走"内置离线神经 TTS"（体积 +60~100MB）方案。

## 七、遗留与备注

- **老板端 Chrome vs 收银端 Electron 音色差异**：二者音色集相同（同一台机器同一批 SAPI 音色），
  感知差异可能来自播放设备/系统默认音色；装自然语音包后两端都会被 `score()` 选到同一拟真音色，天然对齐。
- `v4222_ui_test.mjs` 中"关闭程序"断言在纯浏览器里只能验证走 `window.close` 兜底；
  EXE 内 `DesktopShell.quitApp → pos:quit` 链路需在真机 EXE 上复验（属人工冒烟项）。
- win7 轨（Electron 22.3.27/ia32）本次未重打包；按既定策略"先 Win11 modern 定稿再双轨"。
