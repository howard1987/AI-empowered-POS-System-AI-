## 二、关键实现

### 2.1 系统设置（A1~A4）
- **A1 留在本页**：`settings.js` 增加 `allRows` 缓存与 `curGroup` 当前组记忆；下拉保存后走 `refreshCur()` 只重绘当前组，不再整页拉全量回「全部」。
- **A2 网关自动填充**：`mode` 下拉切到 `real` 时自动 `PUT` 微信/支付宝正式网关地址；用户只需填商户号、APIv3 密钥、商户私钥、证书序列号。
- **A3 负库存开关**：`stock.negative_sales`（商品管理组，默认 false）。sales.module FIFO 批次分配处读取：不允许且可用量不足 → `BizException(50001, 'X 库存不足…')`。
- **A4 系统初始化组**：`init.opening_date`（开业日期）、`init.opening_stock_mode`（开业库存基准 enum：开业大盘点导入/期初建档导入）、`init.opening_note`（说明）。设置分组 6→7。

### 2.2 移动端（B0~B8a）
- **B1 挂单/取单闭环**：
  - 挂单：购物车快照 `POST /pos/held`（服务端留痕不扣库存）→ 清空购物车继续接待。
  - 取单：列表弹窗 → 取出进购物车（可编辑/加减/删行）→ 正常结账。
  - 销单：结账成功自动 `POST /pos/held/:id/pick`（V4.13.9 新端点：`挂单中→已取单`，重复销单幂等返回 `alreadyPicked`），失败不影响交易。
- **左右手习惯**：后台「通用设置 → mobile.hand」（right/left enum）；`applyHand()` 读设置（localStorage 缓存）切 `.hand-left`，CSS 镜像 #ckTools/#ckHoldbar/数量按钮。
- **B3/B5 自动分桶**：后端 `createReturn`/`createPo` 不传 `supplierId` 时按商品 `supplier_default_id` 分桶，每供应商一张单；无主商品拒绝并提示补档案。前端供应商下拉改可选并提示「留空自动分桶」；混退多单时提示逐单补传凭证。
- **B4 随手拍**：`View.aiFree`（ops2.js）——扫码/搜索选商品 → 6 角度逐张拍照上传（水印「随手拍·角度」）→ `POST /ai/samples/free` 角度齐全才收（`source='随手拍'`），进样本库待店长审核；不需要采集任务。
- **B7 单据页**：搜索行 = 供应商关键字 + 日期起止 + 操作人（`canAuditAny` 即管理/店长才显示）；过滤后未审核（未审核/待审核/草稿/进行中/待差异）排前，组内时间倒序；`statusPill` 未审核系红、已审核/已完成绿。入库/退货列表 SQL `LEFT JOIN employees` 补 `maker_name`，行内显示操作人。
- **B8 账号安全**：
  - PWA 我的页：`#mePwd` 弹窗（旧密码/新密码/确认）→ `/auth/change-password`；权限点 pill 走 `/auth/permissions` 服务端中文映射（本地表兜底），不再显示英文 code。
  - Web 员工与权限页：新增「我的账号安全」卡片（本人改密 + 设置密保三问三答，答案 bcrypt 哈希不落明文）；员工行「重置密码」（管理员/店长，`staff.manage`）。
  - 登录页：`忘记密码？` 链接 → 输工号 → 拉密保问题（公开接口只回问题文本）→ 全对自助重置；未设密保提示找管理员重置。

### 2.3 商品档案（C1）
- `shelf_life` 为 SMALLINT（上限 32767）。前端：数值框 `min=1 max=32750` + 单位下拉（天/月/年），保存前换算超范围 toast 拦截；后端 create/edit 同口径校验（40003「保质期换算成天须在 1～32750 天内」）。

### 2.4 对账结算（D1）
- 费用单「+添加行」费用项为 input+datalist：手输新费用项提交时 `POST /purchase/fee-types` 自动建档（同名复用，`custom_` 前缀 code）。
- 方向列改下拉：「供应商应付（-扣减）/供应商应收（+增加）」；`createFee` 落 `direction` 列；列表/协议 `COALESCE(f.direction, t.direction)` 兼容存量（协议行级方向优先）；「陈列费（供应商给店）」→「陈列费」。
