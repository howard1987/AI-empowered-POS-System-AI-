# 超市收银系统 · 打印模版模块细化设计方案（V4.15.6 需求细化）

> 依据三轮问答（2026-09-10）结论整理，替代《AI智能与打印模版-需求梳理与路线图》中的打印部分。  
> 本文档为设计方案，待确认后按分期计划实施。

## 一、打印场景矩阵（四类通道，样式各异）

| 场景          | 设备                    | 纸张/面单                 | 打印通道                       | 指令/技术          |
| ----------- | --------------------- | --------------------- | -------------------------- | -------------- |
| 收银小票        | 80mm / **58mm** 热敏小票机 | 80mm / 58mm 卷纸        | 指令级直驱（WebSerial / 网口 9100） | ESC/POS        |
| 价签 / 秤贴     | 热敏标签机                 | 40×30 / 50×30 / 60×40 | 指令级直驱                      | TSPL / ZPL     |
| **业务单据 A5** | **A4/A5 激光/喷墨打印机**    | **A5（一单一页）**          | **浏览器打印**                  | CSS @page 精确版式 |
| 小票机测试页      | —                     | —                     | 同小票通道                      | —              |

**关键修正**：58mm 小票机与 A5 业务单据打印为本轮补充；业务单据（退货单、报损单、订货单、入库单、盘点差异单、调拨单、对账单）走浏览器打印通道，小票机/标签机无法承担。

## 二、设备适配层（品牌通用适配策略）

| --- | ----------- | ------------ | ---------------------- |
| 小票机 | 芯烨 Xprinter | ESC/POS      | XP-58/XP-80C/XP-235B 等 |
| 小票机 | 佳博 Gprinter | ESC/POS      | GP-58130/58MB/80250 等  |
| 小票机 | 得力 Deli     | ESC/POS      | DL-581P/730C 等         |
| 小票机 | 爱普生 EPSON   | ESC/POS      | TM-T82/TM-m30，含网口      |
| 标签机 | 汉印 HPRT     | TSPL/CPCL    | N41/A300 等             |

| 标签机 | 斑马 ZEBRA    | ZPL          | GK888/ZD 系列            |

### 2.2 适配架构

- **同指令集共享内核**：四家小票机共享 ESC/POS 内核，四家标签机按 TSPL/ZPL 分两个内核；品牌差异只落在「参数配置」层（纸宽、切刀、黑标定位、字符集 GBK、网口端口）。
- **设备档案**：后台「设备管理」为每台打印机建档案（名称/品牌/类型/指令集/纸宽/连接方式 WebSerial|网口|USB/默认与否），收银端与移动端「我的-设备管理」读取。
- **兜底**：未列品牌可选「通用 ESC/POS / 通用 TSPL」，用户自选纸宽即可（覆盖杂牌机）。
- **指令直驱通道**：浏览器 WebSerial（USB/串口）+ 网口 TCP 9100 直发指令，免装驱动；收银页一键出票，与现有 PwaReceipt 同路线扩展。

## 三、收银小票（58mm + 80mm）

- **默认行为**：结账成功自动打印 **1 联**（含钱箱同步弹箱）；收银端「设置→打印」提供开关（自动打/手动补打）。
- **多联**：可配置联数（1~2 联）；开启两联时「顾客联 + 存根联」连续出票，存根联含金额大写 + 签名区。
- **58mm 适配**：同 ESC/POS 内核，纸宽 58mm（可打印区 48mm），模版按窄幅自动精简列宽/字号。
- **重打**：小票图标补打，重打小票顶部加「**重打**」标识；打印留痕（见第六节）。

## 四、价签 / 秤贴（标签机）

- **字段集**（用户选定）：品名 + 售价 + 条码（必含）、单位（¥/斤、¥/袋）、**促销价划线**（原价划线+促销价角标）、产地/规格/保质期到期日。
- **秤贴**：称重后即时出贴（品名/重量/单价/金额/条码/时间）+ 批量价签打印（改价后重打）。
- **面单规格**：40×30 / 50×30 / 60×40 全支持，模版画布按面单尺寸自适应字段布局。
- **批量打印**：商品档案勾选 → 按当前售价/促销价批量出签。

## 五、业务单据 A5 打印（浏览器通道）

- **覆盖单据**：退货单、报损单、订货单、入库验收单、盘点差异单、调拨单、对账单（全部业务单据开放）。
- **版式**：A5 纵向一单一页（明细多自动续页）：门店抬头 + 单据信息区 + 明细表 + 金额合计 + **三方签字栏**（制单人/审核人/业务对方）。
- **通道**：浏览器打印（CSS @page A5），零驱动零安装，电脑/手机均可用；打印预览可选纸。
- **入口与权限**（用户选定）：
  1. 单据详情弹窗「🖨 打印」按钮；
  2. 单据列表复选框批量打印；
  3. 审核通过后自动弹打印（设置可关）；
  4. **权限管控**：仅店长及以上角色可打业务单据（新权限点 `docs.print.a5`）。
- **份数**：默认 1 份，打印前可选 1~3 份。

## 六、打印留痕与重打控制

- **print_logs 表**：单据类型/单据 ID/模版/设备/操作人/份数/时间/是否重打。
- **重打标识**：重打的单据/小票顶部印「重打 + 原打印时间」；后台可查每张单据的打印历史（谁、何时、哪台设备、几份）。
- **补打路径**：单据详情「补打」按钮 → 确认弹窗（pwaConfirm）→ 落留痕。

## 七、模版编辑器（分类型定制，沿用上轮结论）

| 类型            | 编辑形态                  | 原因                    |
| ------------- | --------------------- | --------------------- |
| 卷纸小票（58/80mm） | 区块勾选 + 上下排序 + 所见即所得预览 | ESC/POS 行式打印，拖拽定位无法还原 |
| 标签（价签/秤贴）     | 拖拽画布 + 字段绑定 + 面单尺寸预设  | 位图式定位可精确还原            |
| 业务单据 A5       | 字段区块开关 + 表格列配置 + 打印预览 | 表格型文档，区块化最实用          |

- 预置模版开箱即用；编辑器用于调整字段与顺序；小票脚注广告语/logo 可配。
- 模版按「门店 + 类型」存储，支持导出/导入 JSON 备份。
