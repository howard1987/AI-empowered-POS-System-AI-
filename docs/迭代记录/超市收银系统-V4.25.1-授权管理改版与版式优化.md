## 二、详细设计

### 2.1 开业初始化（`settings.js#loadInitPreview`）

- **风险提示**：
  > ⚠️ 危险操作，请谨慎：点击「执行初始化」后，下方列出的业务数据将被清空且无法恢复。仅用于开业前演练数据清理，或二次开业。员工账号、角色权限、系统设置、商品条码缓存会始终保留。
- **版式**：
  - 顶部红底横幅。
  - 「将清空的业务数据」用 `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))` 卡片网格，每卡显示分类名 + 小计行数 + 表名（等宽字体）/行数。
  - 「始终保留」用绿底卡片单独展示。
  - 「清空范围」用带背景的分组卡片，单选保留基础档案/出厂全清，复选同时清空设备与模板配置。
  - 确认输入占位符改为「请输入「初始化」三个字确认执行」。

### 2.2 变更留痕（`settings.js#loadChanges`）

- **表头**：时间 · 设置项 · 变更内容 · 操作人。
- **设置项**：优先显示 `display_name`，下方灰色等宽字体显示原 `setting_key`。
- **变更内容**：
  - 旧值前缀「改前」，新值前缀「改后」，超长截断并加 `title`。
  - `true/false` → 开/关；`null/undefined/''` → 空；字符串去外层引号；对象取 JSON 前 80 字符。
- 分页保持原 `#chgPager` 静态实现。

### 2.3 分页条定位（`common-ui.js / signatures.js`）

- `pagerBar({ ..., sticky = true })`：默认保持 sticky，传 `sticky: false` 时移除 `position:sticky;bottom:0;` 并追加 `pg-bar-static` 类。
- `signatures.js#drawRecs` 中：
  ```js
  const bar = pagerBar({ page: pg.page, pages: pg.pages, total: pg.total, size: 10, sticky: false });
  ```
  替换原先 `${pg.bar}`，使操作记录分页条跟随 `#sgRecList` 容器，不再浮动。

### 2.4 授权管理改版

#### 前端

- **菜单**：`app.js` 中 `key: 'signatures'` 的 `title` 由「签名管理」改为「授权管理」，icon 由 `✍️` 改为 `🔏`。
- **页面标题**：`signatures.js` 顶部卡片标题改为「🖊️ 签字授权（预采集）」。
- **新增「授权设备」卡片**（位于「操作记录」之后）：
  - 表头：设备码 / 名称 / 状态 / 最后活跃 / 操作。
  - 状态颜色：待授权 `#b5544a`、已授权 `var(--pri)`、已停用 `#8a8577`。
  - 筛选下拉：全部 / 待授权 / 已授权 / 已停用。
  - 操作列：
    - 待授权：✓ 授权（弹出命名 prompt）。
    - 已授权：停用授权。
    - 已停用：启用。
    - 命名、删除。
  - **权限控制**：前端读取 `API.user.perms`，仅 `*` 或 `sys.settings` 显示操作按钮；非管理员只读，并在底部提示「仅超级管理员/老板端可审批或管理设备授权」。
- **文案同步**：`consign.js`、`staff.js` 中所有「签名管理/电子签名管理」提示改为「授权管理」。

#### 后端

- `device.module.ts` 中 `PosDevicesController.list`（`GET /pos-devices`）移除 `@RequirePerms('sys.settings')`：
  - 任何登录员工都可查看本店设备列表。
  - `POST /pos-devices/:id/approve`、`:id/status`、`DELETE /pos-devices/:id` 仍保留 `@RequirePerms('sys.settings')`，确保只有老板/管理员能审批、停用、删除。

## 三、权限矩阵

| 功能 | 所需权限 | 说明 |
|------|----------|------|
| 查看签字授权/操作记录 | 登录即可 | 原签名端点无额外权限点。 |
| 管理签字样本（增删改停用） | 登录即可 | 维持原逻辑。 |
| 查看授权设备 | 登录即可 | V4.25.1 放宽。 |
| 审批/停用/启用/删除/命名设备 | `sys.settings` 或 `*` | 仅老板端/超级管理员。 |

## 四、验证清单（真实环境）

1. 后端 `npm run build` 通过（`device.module.ts` 有改动）。
2. 启动 `start-dev.bat`，`GET /health` 200。
3. 登录老板端 → 左侧菜单应显示「授权管理」。
4. 进入「授权管理」：
   - 顶部卡片标题为「签字授权（预采集）」。
   - 中间「操作记录」分页条滚动时不再浮动在页面底部，而是随容器走。
   - 底部「授权设备」卡片：
     - 显示本店设备（若没有，先开启 `pos.device.auth` 并用新浏览器/隐身窗口登录一次触发登记）。
     - 管理员看到「授权 / 停用 / 启用 / 命名 / 删除」按钮，普通员工只读。
5. 进入「系统设置 → 系统初始化」：
   - 开业初始化页面改为卡片网格 + 绿框保留清单 + 分组单选。
6. 进入「系统设置」→ 查看底部「变更留痕」：
   - 表头为「时间 / 设置项 / 变更内容 / 操作人」。
   - `setting_key` 显示为 display_name + 原键；旧/新值分行，布尔显示开/关。
7. PWA 收银端刷新一次，确认 `sw.js` 升级到 `pwa-shell-v67`。
