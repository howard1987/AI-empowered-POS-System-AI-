## 六、怎么用

**锚点导航**（声明式，最省事）：

```html
<div data-anchor-scope data-anchor-item=".grp-row"> ... </div>
```
容器加两个属性即可，吸顶胶囊条 + 滚动高亮全自动。内容重绘时 JS 调 `anchorNav(view,{scope,refresh:true})`。

**状态筛选**：

```js
box.innerHTML = segHtml([{ k:'', t:'全部', n:120 }, { k:'待审核', t:'待审核', n:8 }], cur);
bindSeg(box, k => { cur = k; reload(); });
```

**玻璃开关**（一般不用手动调，页面已自动接）：

```js
import { applyGlass, loadGlassSetting } from './ui-polish.js';
loadGlassSetting();      // 读后台设置
applyGlass(false);       // 直接关（调试用）
```

### B. 收银端做得好、值得反向移植到后台的

1. **低分辨率紧凑模式 `body.cs-compact`** —— 按视口自动判定降档（列数自适应、字号内距缩小）。后台 30+ 屏在 1366×768 老机器上同样挤，可照搬这套判定。

3. **黄金比例分栏 1.618:1** —— 收银台左右栏比例。后台「详情弹窗 + 列表」类页面可直接复用。

1. **液态玻璃有性能成本**。`backdrop-filter` 在低配收银机 / Win7(Electron 22 / ia32) 上按面积计费 → 只用于浮层小面积，**且已提供总开关一键关**。
2. **骨架屏已取消**（老板决定）。若日后接云端或慢查询，再按页单独加。
3. **大卡片不加 hover 浮起**。见 ③-3。
4. 本次未改动任何后端业务接口、无数据结构变更；`100` 号迁移只 INSERT 一条设置，可安全重放。
