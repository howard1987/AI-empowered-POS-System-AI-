# 超市收银系统 V4.18.6 版本说明 —— USB 小票机指令直驱（收银端打印通道补全）

> 版本号：V4.18.6（接 V4.18.5 收银业务深度 P15 批4）
> 日期：2026-09-11
> 范围：收银端（PWA）+ 打印底座 + Electron 壳；**免迁移**（printers.conn_type 约束自 V4.15.6 起已含 'USB'，后端 PRINTER_CONNS 已留位，本次打通前端与留痕链路）

---

## 一、需求

收银端应支持 USB 驱动小票机。此前现状：

| 环节 | 改造前 |
| --- | --- |
| 后端 `PRINTER_CONNS` | 已含 `'USB'`（建档可选，但 USB 建档被要求必填连接地址） |
| `/printers/:id/send` | USB 直接拒绝：`仅网口支持服务端直发` |
| 标签直驱 `/printers/:id/labels` | USB 被拒：`USB/蓝牙请走系统驱动` |
| PWA 打印内核 `printers.js` | USB 落入兜底：`暂不支持指令直驱，已用浏览器打印`（弹系统打印框，体验差） |
| 设备管理（我的页） | 无 USB 小票机入口 |

## 二、实现

### 2.1 通道设计（与既有三级通道对齐，成为第四级）

```
直驱四级：串口（WebSerial）→ USB（WebUSB）→ 网口（后端 TCP 9100 代理）→ 浏览器 iframe 兜底
```

USB 直驱采用 **WebUSB（usb.requestDevice / claimInterface / bulk transferOut）**，
免系统驱动、免打印对话框，与 WebSerial 串口直驱同一体验：
- 连接须在**用户手势内**（设备管理「连接」按钮）；连接后本源授权持久，
  刷新/下次启动经 `navigator.usb.getDevices()` **静默自动重连**（`pwa_usb_printer` 记 vid:pid），
  结账自动打印无需再次手势。
- 接口选择：优先含 bulk OUT 端点的接口（USB 打印类 class 7 天然命中；厂商自定义接口亦兼容）。
- 分块发送：4096 字节/块，规避部分机型端点缓冲上限。
- 被系统驱动独占时给出明确提示（「未找到打印接口…请卸载驱动或改网口」）。

### 2.2 改动明细

**后端 `device.module.ts`**（3 处）
1. USB 建档免连接地址（与串口同待遇）：`if (!['串口','USB'].includes(connType) && !addr) throw`；
2. `/printers/:id/send`：串口/USB 同分支——字节由浏览器直发，服务端落 print_jobs
   `（USB直驱 N 字节）` 留痕，应答 `channel:'usb'`（前端附 `bytes` 计数，修复串口 0 字节留痕）；
3. `/printers/:id/labels`：串口/USB 同分支——返回 `dataBase64` 交浏览器直发，
   错误文案改为「标签直驱仅支持网口/串口/USB（蓝牙请走系统驱动）」。

**PWA `printers.js`**（打印内核）
- 新增 `connectPrinterUsb()` / `usbResume()` / `usbSend()` / `usbConnected()`；
- `directPrint` 增 `USB` 分支（Android Chrome 亦支持 WebUSB，未限手机端）；
- `kickDrawer` 弹箱支持 USB（ESC p 经 USB 小票机转发，RJ11 接钱箱），与网口并列；
- `disconnectPrinter` 同时关串口与 USB；`printerConnected()` 含 USB；
- 自动打印 toast 通道名映射 `{network:网口, serial:串口, usb:USB}`；
- 导出新增 `connectPrinterUsb` / `usbConnected` / `usbResume`。

**PWA `app.js`**（我的 → 设备管理）
- 新增「🔌 USB 小票机」行（`navigator.usb` 存在即显示：电脑 Chrome/Edge + 安卓 Chrome），
  状态 pill（USB直驱/未连接）+ 按钮 连接/测试打印，错误 toast 反馈。

**Electron `frontend-desktop/src/main.js`**
- `setPermissionRequestHandler` 放行 `usb`（原仅 `media`）；
- `setDevicePermissionHandler`（deviceType==='usb' 自动授权）+
  `select-usb-device` 自动选中首个设备——kiosk 无选择弹窗场景可用；
  未来 PC EXE 包 PWA 收银台时同链路直接可用。

**SW**：`pwa-shell-v51 → v52`。

## 四、遗留与备注

- **蓝牙**通道仍走系统驱动（维持 V4.15.8 决策：Web BLE 按机型另行评估）；
- `directPrint` USB 分支未禁移动端：安卓 Chrome 支持 WebUSB（OTG 场景），保留；iOS 不支持自动回落浏览器打印；
- Electron 壳当前 renderer 仍是旧 T16 页面（非 PWA 收银台），WebUSB 放行为 P16 EXE 打包预埋；
- 临时验证脚本与 Edge 临时目录按用户要求保留未删（`backend/v4186_ui.tmp.js`、`.workbuddy/tmp-edge-v4186`）。
