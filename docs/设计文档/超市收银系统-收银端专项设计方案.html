1. 背景与现状

1.1 现状盘点（代码事实）

  • 收银目前是 PWA「作业」Tab 里的子视图（checkout.js 856 行），入口层级深，与入库/盘点混在同层，风格互相牵制；
  • 已有能力：价目表 IndexedDB 离线缓存、扫码枪直扫/搜索联想、购物车、现金/扫码/余额三选一支付、扫码通道真扣款（USERPAYING 轮询）、挂单/取单、扫码购核销、语音播报、电子秤串口读重、漏扫检测、应急收银、断网暂存补传、条码秤格式解析、即时秤贴；
  • 设备连接入口在「我的-设备管理」，但无状态感知、连接不持久、失败静默降级；
  • 支付无找零界面、无组合支付；退货要跨页面去作业页；无交接班界面。

1.2 问题定性

收银是全店最高频、设备最密集、资金风险最集中的操作。本专项按「一单的完整生命周期 + 人钱物流动」全面梳理，补齐功能、异常路径、设备底座三块。

3. 载体与范围：A + C 双端

A 端 · PWA 独立收银台（先做）

  • 一级「收银」入口，登录后直落全屏收银台，无底部 Tab 干扰；
  • 手机/平板/收银机浏览器通用；
  • 复用现有底座：离线价目表、支付通道、设备连接、小票/钱箱钩子——改动集中在信息架构与布局层。

C 端 · PC 收银机专属端（基于已实施 Electron 端演进）

修正（2026-09-11 补确认）：初始版已实施 Electron 收银端 frontend-desktop（V4.8.x，Win7/Win11 安装包齐备），P16 不新建，在其基础上按新设计补功能。
  • 保留已验证底座：双屏输出（主屏 kiosk + 副屏顾客信任屏）、外设适配器（serialport 直驱）、小票模版、安装包链路；
  • 副屏已实施元素全保留：明细逐行滚动、应收大字、「会员已帮您节省 ¥X」、会员卡（脱敏手机、储值/分红/积分、等级系数、累计与失效分红透明展示）、支付成功页；
  • 副屏增强（P16）：支付过程引导（扫码「请出示付款码」/现金应收·实收·找零大字）、店招欢迎语常驻、空闲轮播内容后台可配；
  • 设备通道以 Electron 原生适配器为主（serialport 直驱，无手势限制），网口走后端转发；
  • F1~F12 键盘流（快捷键体系见 §12）；复用 A 端全部后端接口与数据层。

4. 布局与视觉

视觉规范

  • 基调：延续全店浅色 + 品牌绿；合计/找零/支付区用深色高对比条突出金额（≥28px 加粗）；
  • 密度：大按钮低密度，触控目标 ≥48px——收银是操作不是浏览；
  • 设备状态灯：顶部常驻四盏（扫码枪/电子秤/小票机/钱箱），●绿=在线、●红=掉线可点重连、●黄=降级通道。

6. 设备连接方案（八项）

决策点结论
① 状态感知收银台顶部常驻四盏设备灯，进收银台自动检测一轮，掉线可点重连；班前「一键连齐全套」
② 连接持久化指纹记忆（端口标识/网口 IP/蓝牙名）+ 一键重连；WebSerial 仍需一次手势（浏览器硬限制），网口设备走后端免手势直连
③ 扫码枪收银台运行期全局键盘监听（HID 枪特征节奏收码，不依赖焦点，弹窗/结算页都能收）；手机配隐藏输入框防软键盘；不换枪
④ C 端通道基于已实施 Electron 端演进：设备通道以 Electron 原生适配器为主（serialport 直驱，无手势限制），网口走后端转发；不做浏览器本地打印代理
⑤ 绑定粒度C 端设备绑台位（存台位档案，换人接岗不重连）；A 端手机设备绑登录人
⑥ 打印降级网口失败 → 自动试串口 → 再试系统打印，每级明示实际通道（如「已走串口通道出票」）；全失败才报错给重试；状态灯同步变黄
⑦ 手机连秤维持手输重量（放开安卓串口秤被否，规避 OTG 线材支持问题）
⑧ 语音播报默认本机喇叭，蓝牙音箱可选自动切换
现状病灶对照：设备无状态感知（用到才报错）→ 状态灯+自检；连接不持久（刷新即忘）→ 指纹+一键重连；打印静默降级 → 每级明示通道。

7. 离线策略（分级降级）

离线可用

  • 扫码/搜索/快捷格
  • 数量改/删行/开放键
  • 现金记账支付、挂单取单
  • 锁屏

仅在线

  • 扫码通道扣款（自动提示改现金记账）
  • 退货原路退
  • 交接班提交、积分抵现/挂账校验
  • 语音 AI 查询（本地规则兜底）

断网时自动降级提示，不阻塞收银；断网暂存补传沿用现有底座。

8. 设置与权限

  • 设置项内嵌收银台：店长权限的「⚙ 收银设置」面板就地改（快捷格数量、抹零方式、退货限额、交接班容差、锁屏超时、积分比例、语音开关、客显文案等）；
  • 底层仍存 system_settings 同一套键，日后迁系统设置页只需换入口；
  • 权限主线：抹零/赠品/开放键可选权限、整单自定义折扣、最低售价放行、退货超限、无交易开钱箱、挂账超限——全部留痕进操作记录。

  • 蓝色主题（已定品牌绿）；预约/预付卡/礼券销售/合伙人/邮寄管理（不适用本期）。
