# 超市收银系统 V4.15.2 · 移动收银挂单修复与决策中心明细整改

## 一、移动端-移动收银（backend/public/pwa/checkout.js + index.html）

1. **按钮改名**：「连接电子秤」→「电子秤」、「连接钱箱」→「钱箱」、「AI 拍多件（免扫码）」→「AI拍」；购物车读重提示文案同步（「先点上方「⚖ 电子秤」」）。
2. **串口不支持不再报错**：render 时检测 `navigator.serial`，不支持（手机 WebView/非 Chrome）→ 电子秤/钱箱按钮直接置灰并标注「（不支持）」，点击守卫文案同步人话化（"此设备浏览器不支持串口连接…"）。桌面 Chrome/Edge 行为不变。
3. **取单/挂单/结账并列固定**：`#ckHoldbar` 从页面流移入 `.ck-sticky`，与结账同排（取单:挂单:结账 flex 1:1:1.6）；新增 `.ck-actions` CSS；`.hand-left` 镜像选择器从 `#ckHoldbar` 改为 `.ck-actions`；删除 `.ck-sticky #ckGo{width:100%}` 旧规则。
4. **挂单点击无反应（根因修复）**：`#ckTake`/`#ckHold` 此前**从未绑定 onclick**——holdOrder/takeOrder 函数定义了但没接线。bind() 中补绑。
5. **原生 confirm 换 pwaConfirm**：挂单确认、删除挂单确认两处（原生 confirm 在部分手机 WebView 静默返回 false，同 V4.14.2 docs.js 整改原因）。
