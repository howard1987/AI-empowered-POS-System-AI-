# 超市收银系统 —— AI 智能与打印模版：需求梳理与实现路线图

日期：2026-09-10（基于三轮问答梳理）
结论先行：AI 四线并进但**分期解锁**；打印**全场景模版编辑器**一步规划、分批实现。

---

## 一、AI 智能需求（问答结论 → 实现方案）

### 1. 识别增强 —— 路线：「快中求准」+「分步拍引导」
| 需求 | 结论 | 实现方案 |
|---|---|---|
| 相近 SKU 混淆 | 自动区分到什么程度算什么，剩下靠更聪明的候选卡片，保收银节奏 | ① 候选卡片差异高亮（类别/价格/规格差异点标红）+ 按使用频率排序；② 易混 SKU 自动提示「补拍侧面/背面样本」建库增强；③ 文字 rerank 强化（瓶身品牌字佐证已有，加大分权重可配置） |
| 多件识别不准 | 分步拍引导 | 拍摄引导交互：单张建议 3~5 件，拍完展示已识别/未确认件数，引导补拍；结果页件数快速加减修正 |

### 2. 决策自动化 —— 路线：三档开关 + 成熟度解锁
- **后台设置三档**（按决策类型分别设置：定价 / 补货 / 促销）：`手动确认` → `半自动` → `全自动`
- **第一阶段全部人工确认**（现状即此档）
- **解锁机制**：AI 统计每类决策的采纳率/执行后效果，成熟度达标（如采纳率 ≥ 70% 且连续 N 周）后，后台提示可开启下一档
- 半自动 = 生成草稿（补货草稿 PO / 幅度内改价预览）待确认；全自动 = 阈值内直接执行 + 全量留痕 + 一键回滚

### 3. 销售预测 —— 三个用途，决定模型设计
- **订货量预测**（主用途）：预测明日/下周销量 → 联动补货建议生成订货参考量；统计模型起步（移动平均 + 星期/同期系数），不依赖外部服务
- **损耗预警**：滞销/临期风险提前预警，联动促销建议
- **节假日备货**：节日/周末维度备货提醒（提前 N 天的商品清单）

### 4. 新交互能力（三项都做，排期见路线图）
- **经营问答**：对话式查数据，覆盖 经营总览（销售/毛利/客单价/时段）、商品分析（畅销滞销/利润 Top/单商品历史）、库存供应链（库存/临期/损耗/在途）；人员与资金域暂不开放
- **语音增强**：在现有 PwaTTS 基础上扩展收款/告警播报场景
- **智能对账**：进销存差异自动比对、支付渠道对账异常的人话解读

## 二、打印模版需求（两轮问答收敛 · 2026-09-10 细化定稿）

> 详细设计见《超市收银系统-打印模版模块-细化设计方案.md》，本章为融合后的结论与总计划。

### 2.1 打印场景矩阵（四类通道，样式各异）
| 场景 | 设备 | 纸张/面单 | 打印通道 | 指令/技术 |
|---|---|---|---|---|
| 收银小票 | 80mm / 58mm 热敏小票机 | 80mm / 58mm 卷纸 | 指令级直驱（WebSerial / 网口 9100） | ESC/POS |
| 价签 / 秤贴 | 热敏标签机 | 40×30 / 50×30 / 60×40 | 指令级直驱 | TSPL / ZPL |
| 业务单据 | A4/A5 激光/喷墨打印机 | A5（一单一页） | 浏览器打印 | CSS @page 精确版式 |
| 测试页 | — | — | 同所属通道 | — |

### 2.2 设备适配（品牌通用适配 · 指令级直驱）
- **小票机预置**：芯烨 Xprinter / 佳博 Gprinter / 得力 Deli / 爱普生 EPSON → 共享 **ESC/POS 内核**，品牌差异只落参数层（切刀/黑标/网口/字符集）
- **标签机预置**：汉印 HPRT / 佳博 Gprinter / TSC / 斑马 ZEBRA → **TSPL + ZPL 双内核**
- 未列品牌走「通用 ESC/POS / 通用 TSPL」兜底；设备档案（名称/品牌/类型/纸宽/连接方式/默认机）存 print_devices，后台与移动端「我的-设备管理」共用

### 2.3 关键行为（用户确认）
- **收银小票**：结账成功**自动打 1 联** + 收银端设置开关（可关/手动补打）；多联可配 1~2，存根联含金额大写+签名区
- **价签字段**：品名+售价+条码（必含）、单位、促销价划线角标、产地/规格/保质期；批量出签+称重即时秤贴
- **A5 业务单据**：退货/报损/订货/入库/盘点/调拨/对账七类；入口=详情打印+列表批量+审核后自动弹（可关）；店长及以上权限（`docs.print.a5`）
- **打印留痕**：print_logs 记录每次打印（人/设备/份数/时间），重打自动加「重打」标识

### 2.4 模版编辑器 —— 分类型定制
| 模版类型 | 编辑形态 | 原因 |
|---|---|---|
| 卷纸小票（58/80mm） | 区块勾选 + 上下排序 + 所见即所得预览 | ESC/POS 行式打印，自由拖拽打不出来 |
| 标签（价签/秤贴） | 拖拽画布（字段块自由摆位、字号/条码可调） | 位图打印支持绝对定位 |
| 业务单据 A5 | 字段区块开关 + 表格列配置 + 打印预览 | 表格型文档区块化最实用 |
- 多套模版管理：新建/复制/重命名/删除，按场景绑定默认；预置「标准模版」兜底；JSON 导出导入
