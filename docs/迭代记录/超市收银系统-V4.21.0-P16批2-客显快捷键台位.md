## 一、客显增强接新收银台（P16 主项）

**架构**：主屏（PWA 收银台）→ `POST /display/push`（登录）→ 后端进程内快照（每店一帧）→ SSE 广播 → 副屏。
副屏 = 任意浏览器第二窗口或 EXE secondWindow，打开 `GET /display/`（`backend/public/display/index.html` 静态页，免登录靠局域网边界）。

- **后端 display 模块**（`backend/src/modules/display.module.ts`）：
  - `POST /display/push`：存快照 + 广播，返回 `{clients:N}` 供主屏连接灯（E3 断连感知）
  - `GET /display/events?store=N`（@Public）：SSE；握手即发当前快照（副屏晚开/重连立即还原画面）；25s 心跳
  - `GET /display/cfg?store=N`（@Public）：店招（store.info.name）+ 欢迎语（display.welcome）+ 轮播（display.ads JSONB）
- **副屏页面**：店招+欢迎语常驻顶栏；购物明细/应付/已省；会员卡（手机号脱敏）；台位标签；
  **支付引导大字**——扫码通道「请出示付款码 · 扫码后请输密码」，现金通道应收/实收/找零三联大字；
  支付成功 ✓ 层（6s 自动回）；空闲轮播（8s/条，支持 emoji/图文，dots 指示器）；
  EventSource 断线自动重连（E3：断连显示「等待主屏」，恢复自动续显，交易不中断）
- **主屏推送**（cashier.js `pushDisplay`）：车变（renderCart 350ms 去抖）/进结算/通道切换/实收找零输入/付款码输入/落单 done 帧全节点推送；15s 心跳刷新连接数；`pos.display.push` 开关（关=不推）
- **客显连接灯**：顶栏新增「客显」灯（绿=副屏在线/黄=暂无副屏/红=推送失败或已关），点按提示打开方式；设置面板「🖥 打开副屏」一键开第二窗口（拖到副屏 F11 全屏）
- **EXE**：`ui:'pwa'` 时 secondWindow 自动加载 `server + /display/`

## 二、快捷键自定义 + 收款双键 + F1 键位说明

- **键位映射**：`pos.cashier.hotkey_map`（JSONB `{pay,hold,take,repeat,print,lock}`，默认 F9/F2/F4/F6/F7/F8）；keydown 按 map 分发；F1=键位说明弹窗（固定不可改，拦截浏览器帮助）
- **可视化编辑器**：设置面板「快捷键自定义」——点按钮→按键捕获（F1~F12 或单字母；**冲突自动互换**；ESC 取消）；保存即生效
- **EXE 全局键同步**：`DesktopShell.registerHotkeys(keys[])` → IPC `pos:hotkeys-register` → 注销全部+按新映射注册；进收银台/保存后自动同步
- **收款双键**：结算弹窗 **回车=收款打小票，空格=收款不打小票**（小额免票省纸，仅现金通道；输入框/按钮聚焦时不劫持）；成功提示「本单未打小票（空格收款）· 可补打」；`skipPrint` 经 doCheckout→afterSaleSuccess 透传
- **设置保存健壮化**：12 项逐项保存+失败收集明示（`⚠ 部分设置保存失败：xxx`），PwaTTS.loadCfg 改 fire-and-forget 不阻塞保存——根因是 V4.19.0 遗留缺种 `pos.print.browser_fallback`（089 已补种，缺种时保存整包静默失败）

### 本期坑（防复发）
1. **联表 store_id 歧义**（第 2 次）：tables.list JOIN devices 后 `store_id=$1` 歧义 500 → 一律 `t.store_id`。凡 JOIN devices/printers/employees 的查询，条件列必须带表前缀。
2. **headless 复用 profile 的磁盘缓存**：改前端文件后 CDP 回归可能跑旧代码，症状诡异（handler「卡死」实为旧逻辑）。脚本必须 `Network.setCacheDisabled` 或每次换全新 `--user-data-dir`；定位先 `fetch('./xx.js?bust=')` 验证特征串。
3. **settings PUT 缺种 40404**：新设置键必须种子先行，收银设置保存链路逐项容错已加。
4. 测试脚本编辑时弄丢「点击保存」语句导致 modal 滞留吞后续按键——保存/关闭类动作后必须断言 modal 状态。
