## 3. 端口配置

- `PORT` 环境变量，**默认 3000**（`main.ts:77` `Number(process.env.PORT || 3000)`）。改成 3100：设 `PORT=3100`（当前联调即以 env 方式传 3100；项目无 `.env` 文件，但已引入 dotenv，可落 `backend/.env`）。
- `app.listen(port)` **未绑定 host** → Node 默认监听全部网卡（0.0.0.0/::），局域网可达 ✔。
- 附加端口：`HTTPS_PORT`（默认 3443，自签证书自动生成于 `backend/certs/`，检测到 IP 变化自动重签；mDNS 广播 `pos-server.local`）。

## 4. 静态托管能力

- **已支持**：`app.useStaticAssets(join(__dirname,'..','public'))` —— `public/` 下任何子目录自动按根路径可达（现有 `/pwa/`、`/boss/`、`/member/`、`/display/`、`/uploads/` 就是这么挂的）。
- 因此**挂 `/admin`、`/pos` 无需改 main.ts**：构建脚本把 `frontend-web → public/admin`、`pwa → public/pos`（复制/同步）即可，同源还免掉 CORS。
- `/health` 健康检查已存在 ✔（`{"code":0,"data":{"status":"ok",...}}`）。
- 上传目录外置：`AI_UPLOADS_DIR` env 可指向数据盘/NAS，`/uploads` 路由跟随。

## 9. 打包/部署坑位清单

1. **端口**：PORT 默认 3000（要 3100 必须显式设）；Windows 防火墙需放行入站 TCP 3100（HTTPS 另放 3443）；3100 被残留旧进程占用时 EADDRINUSE。
2. **跨域**：自研 CORS 白名单=回环+私有 IPv4+`*.local`+同主机，外网 403。同源托管 /admin /pos 后浏览器端无 CORS 问题；Web 后台独立 8088 部署才依赖 CORS。
3. **静态资源路径**：两个前端全部相对路径 `./` 引用，子路径挂载安全；但 PWA 的 SW scope/manifest start_url 均相对——换目录（/pwa→/pos）后**已装设备的旧 SW 缓存仍指向旧路径**，需保留旧路径一段时间或提示重装。
4. **路由刷新 404**：hash/无路由，无此问题（见 §5）。
5. **PWA 图标/安装限制**：manifest 仅 `icon.svg`（purpose:any），**无 192/512 PNG、无 apple-touch-icon**——Android Chrome 的"安装"按钮与 iOS 主屏图标可能异常；**HTTP 下（http://IP:3100）Android 不满足 PWA 安装条件，且摄像头 getUserMedia 不可用（扫码/拍照失效）**——必须走系统自带的 HTTPS:3443（自签证书需手动信任）或 mDNS 域名 `https://pos-server.local:3443`。
6. **桌面端服务器地址**：已有首启向导（V4.22.1）写 desktop-config.json，无需再手工放文件；EXE 无签名，SmartScreen 需点"仍要运行"；Win7 轨需 `.NET 4.x/VC 运行库` 基本系统自带。
7. **打印机/扫码枪**：扫码枪=HID 键盘模拟免权限；小票机=WebSerial/WebUSB（浏览器需手势授权，EXE 已放行）或网口 9100/winspool 直发（任意浏览器客户端生效、免浏览器权限）。
8. **依赖拉取**：无 lockfile + `xlsx` 走 sheetjs CDN tgz 源 + onnxruntime-node 体积大——离线打包必须用"打包好的 node_modules"，不能现场 npm i；electron-builder 下载 Electron 需 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 否则极慢。
9. **双后台并存**：`frontend-web`（24 屏完整后台，:8088）与 `backend/public/index.html`（初版联调骨架）同时存在；`boss/` 是老板看板——/admin 应挂 frontend-web，骨架页建议下线（见待确认 Q2）。
