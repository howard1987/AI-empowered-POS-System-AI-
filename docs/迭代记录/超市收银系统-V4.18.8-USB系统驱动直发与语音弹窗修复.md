# V4.18.8 — USB 小票机系统驱动直发（POS-80 实测打通）+ 试听修复 + 弹窗遮挡修复

> 日期：2026-09-11　前置：V4.18.7（SW v53）　本次后 SW **v54**，后端需重启（无数据库迁移）

## 0. 用户反馈（真机，收银端 PC）

1. 设备管理里**没有 USB 小票机选择**：已安装 POS-80 小票机 Windows 驱动（打印机和扫描仪里可见、状态空闲），但软件识别不到（截图弹的是 WebSerial 串口选择器，COM 列表无 POS-80）
2. 设置里「试听当前音色」**没反应**，部分音色无声
3. 收银设置弹窗**界面被遮挡**（保存按钮滚不见、下拉展开溢出）

## 1. 根因

### 1.1 USB 小票机（核心认知修正）
- V4.18.6 的 WebUSB 方案**对已装驱动的机器天然不可见**：POS-80 安装厂商驱动后，USB 打印接口被 Windows `usbprint.sys` 独占，Chrome WebUSB `requestDevice` 只枚举 WinUSB/libusb 类接口的设备 → 选择器里不会出现 POS-80
- WebSerial 同理：USB 打印机类不模拟虚拟 COM 口 → 串口选择器里也没有
- **正解：走系统驱动 RAW 直发**（winspool RAW datatype）——ESC/POS 字节直接交 Windows 打印驱动，零折腾、无需改驱动/Zadig。后端就跑在本机（localhost），具备直发条件

### 1.2 试听无声（两个叠加原因）
- `PwaTTS.say()` 是 async：`await loadCfg()`（8 个设置键网络请求）之后才 `speak()`，已**脱离用户点击手势上下文** → Chrome autoplay 策略静默拦截
- 音色本身：Google 系在线音色需连 Google 服务（国内无声）；Edge「Natural」拟真声仅 Edge 浏览器可用，Chrome 选中无声 → 「部分无声音播放」

### 1.3 弹窗遮挡
- `.modal .sheet` max-height 82dvh 内容超长时保存按钮被滚走；底部贴边布局加剧遮挡感

## 2. 改动明细

### 2.1 后端（backend/src/modules/device.module.ts + scripts/rawprint.ps1）
- **`scripts/rawprint.ps1`**（纯 ASCII，PS 5.1 兼容）：C# RawPrinterHelper P/Invoke winspool（OpenPrinter→StartDocPrinter RAW→WritePrinter），`-Printer <系统打印机名> -File <bin>`，输出 `OK|字节数` / `ERR|原因`
  - ⚠️ 坑：P/Invoke 签名 `StartDocPrinter(..., ref DOCINFOA)` 必须 ref；`WritePrinter` 收 `byte[]`（IntPtr+AllocHGlobal 写法在 PS5.1 报封送错误）
- **`osRawPrint()` helper**：写临时 bin → spawnSync powershell → 解析 OK|N / ERR|；20s 超时；finally 删临时文件
- **`GET /printers/os-list`**（printer.manage）：`Get-Printer` 枚举本机打印机（name/port/online）
  - ⚠️ 坑：spawnSync 默认 GBK 输出被按 utf8 解码 → 中文名乱码（L3250 Series(网络)），命令前缀 `[Console]::OutputEncoding=UTF8` 修复
- **`POST /printers/:id/send`**：USB 且 `conn_addr` 非空 → 后端 RAW 直发（留痕「系统驱动直发「POS-80」 N 字节」，失败 40005 带原因+记失败历史+设备标故障）；`conn_addr` 空 → 保持 V4.18.6 WebUSB 浏览器直发
- **`POST /printers/:id/labels`**：USB+addr 同步走后端 RAW；空走 WebUSB b64 回传
- `rawprint.ps1` 首跑实测：真机 POS-80 返回 `OK|4`（4 字节 ESC@ 初始化被驱动接收）；API 级 RAW 直发 costMs≈2311（首次含 PS 启动+Add-Type 编译，属正常）

### 2.2 PWA 收银端（printers.js / app.js / cashier.js / index.html / tts.js）
- **printers.js**：`directPrint` USB 分支按 `conn_addr` 分流——非空走后端（与网口同构，`dataBase64` 上行）；空走 WebUSB。`kickDrawer` 同步分流。toast 通道名映射加 `os:'系统驱动'`
- **app.js 设备管理**：USB 行改造——
  - 默认机为 USB+绑定 → 绿 pill「系统驱动：POS-80」+ 按钮「测试打印」（直接 RAW 测试）
  - 未绑定 → 灰 pill「未绑定」+ 按钮「绑定本机打印机」→ 弹窗列 os-list（🟢/⚪ 在线态+端口名）→ 选择 → 复用/新建 USB 打印机记录（`connAddr=系统打印机名`）→ 自动设默认
  - WebUSB 直驱保留为未装驱动机器的备选（绑定前若已 usbConnected 优先测试）
- **tts.js `speak()`**：加 `opts.onFail` + `onstart/onerror` + 2.5s 无输出 watchdog（在线音色断网典型表现）——无声不再无息
- **cashier.js 试听按钮**：改**同步调用 `PwaTTS.speak()`**（保住点击手势，关键修复）；「跟随老板端」试听不清空老板端音色缓存；失败 toast 明示音色名+原因+建议。音色下拉标注细分：「（拟真·Edge）」「（需联网）」「（本地）」
- **弹窗遮挡**：`.modal .sheet` max-height 82dvh→**90dvh**；收银设置保存按钮 `position:sticky; bottom` 常驻可见 + sheet 尾部留白
- **sw.js**：v53 → **v54**

## 4. 用户使用指引（POS-80 场景）

1. 收银端「我的 → 设备管理」→「🔌 USB 小票机」行点**「绑定本机打印机」**
2. 弹窗选 **POS-80**（🟢）→「绑定并设为默认」
3. 点「测试打印」出测试小票即全通；此后收银出票自动走该通道（80mm 版式、2 联=顾客联+存根联规则照旧）
- 钱箱若 RJ11 接在 POS-80 上，「网口/USB 弹箱」同步可用

## 5. 遗留与注意

- RAW 直发经 PowerShell spawn，单张延迟 ~1-2s（收银结账异步不阻断；如需毫秒级可后续换预编译 C# exe 或 node-ffi，暂无必要）
- os-list 枚举含虚拟打印机（PDF/XPS/Fax），绑定选错无危害（打不出时 40005 明示原因）
- WebUSB 通道保留：未装驱动的机器（如部分裸发票据机）仍可「USB直驱」
- 临时测试脚本（v4187b_ui.tmp.js、rawtest.tmp.* 等）与 Edge 临时 profile 按用户要求保留未删
