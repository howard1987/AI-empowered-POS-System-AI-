## 一、P6 识别增强（快中求准 + 分步拍引导）

### 1. 分步拍引导（PWA ai-scan.js + 后端 /ai/recognize）
- 弹层新增**分步拍引导条**：单张建议放 3~5 件、平铺不重叠；每轮多件识别回报「已识别 X 种 / Y 件 · 待确认 Z 件」；待确认偏多时提示「分开摆平/换角度再拍一张」。
- 后端多件识别（clip-multi）返回 `guide = { suggestedPerShot:'3~5', recognizedKinds, recognizedPieces, unconfirmedPieces, suggestMore }`（未确认 = 外观相近件 + 低置信件之和）。
- 结果页件数 **± 修正**沿用既有交互（人工改数冻结 AI 断言并作纠正信号回传，闭环不变）。

### 2. 候选卡片差异高亮 + 频率排序
- 后端 `enrichCandidates`：候选补齐**类别 / 售价 / 单位 / 规格 / 近30天销量**字段（一次批量 SQL）。
- 前端渲染卡片副行展示上述字段；候选集内**取值不一致的字段自动标红**（价格/规格/类别一眼看出区别点）。
- 展示排序 = conf + 频率加成（`ai.rerank.freq_weight` 默认 0.03，封顶 freq100/月），**只影响候选卡片展示顺序，绝不影响三门槛命中判定**（"融合分只排序"铁律不变）。

### 3. 易混 SKU 补拍引导
- 单件 ambiguous / 多件存在相近待确认件时，返回 `reshoot = { productIds, text }`；PWA 显示红色引导条 +「📸 去补拍样本（建库增强）」按钮，直达 AI 训练采集页。

### 4. rerank 分权重可配置
- `ai.rerank.text_weight`（默认 0.1，0~0.3，0=关闭 rerank）：图文对齐文本信号的拉动权重，单件/逐件共用；设置页可调。

## 二、P7 决策自动化（三档开关 + 成熟度 + 回滚）

- **三档开关**：`ai.decision.modes` jsonb，定价/补货分域各自设置 `手动确认 / 半自动(生成草稿待确认) / 全自动`；决策中心页新增「⚙️ 决策自动化」卡（下拉选择 + 成熟度状态 + 保存，需 sys.settings）。
- **成熟度统计**：`GET /brain/maturity` 分域统计近 4 周**分周采纳率 + 连续达标周数 + 已决策样本数**；门槛 `ai.decision.maturity`（采纳率 ≥70% 且连续 2 周达标且 ≥5 条）。未达标显示未解锁原因；**全自动但未解锁 → 自动保持人工确认并在建议里写明原因**。
- **执行引擎化**：`AibrainEngine.executeSuggestion`（人工/全自动共用同一实现）——补货生成采购单、定价按确认价真改售价；**执行即记 `rollback_json` 回滚快照**（定价=逐条改前原价；补货=PO id/单号），全自动执行落 `auto_executed=true`（列表显「🤖 自动执行」标记）。
- **一键回滚**：`POST /brain/suggestions/:id/rollback`——定价还原原售价；补货取消未到货采购单（已开始到货则提示人工处理）；`rolled_back_at` 留痕，不可重复回滚。
- 半自动 = 现状流程（建议待处理=草稿，人工确认后执行）。

## 三、P8 销售预测（订货联动 + 备货 + 预警）

- **订货量预测联动补货**：restock 优先取未来 7 天 `forecast_snapshots` 预测销量作日均参考（预测 7 天量 ÷ 覆盖天数；无预测商品回落移动平均），明细加 `forecast7` 字段，建议理由标注预测版/回落版。
- **节假日备货**：新引擎 `holidayStock`——内置节日表（2026/2027 公历硬编码，元旦/春节/清明/五一/端午/中秋/国庆 + 系数 1.2~1.8）+ 提前 N 天（`ai.holiday.lead_days` 默认 14）→ **分品类增量备货清单**（未来 7 天预测 × (系数−1) 向上取整）；无节日时周五生成周末轻提醒（系数 1.2）；按日去重不轰炸。建议域新增枚举值「备货」。
- **损耗/滞销预警**：由既有 expiryLoss（15 天临期 8 折去化）与 assortment（零动销高库存淘汰/停补）承接，本期问答侧补「滞销」「报损」查询入口。

## 四、P9 经营问答 + 智能对账 + 语音增强

- **问答扩面（qa 新增 8 条路由）**：经营总览（销售额/毛利/客单价/环比昨日）、分时高峰（今日逐小时销量+峰值）、滞销分析（30 天零动销且库存 ≥10）、利润排行（30 天 line_profit TOP5）、单商品销量（「XX卖了多少」→ 名称模糊匹配 30 天销量+库存）、在途采购（未到货量）、报损损耗（30 天单数/件数/成本/TOP）、智能对账。
  - 路由优先级修正：单商品查询（^…$ 锚点）放最前；「利润排行」用 `利润(?!排|榜)` 避免被「毛利」路由截胡。
- **智能对账**：`POST /brain/recon-insight`——① 支付渠道对账：bill_recon_runs 近 5 笔差异单（渠道/日期/差异行数/账单 vs 系统）人话解读；② 进销存差异：全店「批次在库合计 ≠ 现存量」商品比对（FIFO 账实校验）。决策中心新增「🔍 智能对账体检」按钮卡。qa 问「对账」同源。
- **语音增强**：`PwaTTS.alert(text)` 告警播报（`ai.voice.alerts` 开关默认开；语速 0.95 前缀「告警」）；PWA 作业页进入时自动播报最新一条未读经营告警（sessionStorage 每条每设备只播一次）；收款播报沿用 V4.13.8 `PwaTTS.cash`。
