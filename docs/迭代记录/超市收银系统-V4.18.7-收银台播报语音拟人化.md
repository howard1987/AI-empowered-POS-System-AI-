# 超市收银系统 V4.18.7 版本说明 —— 收银台播报语音拟人化 + 多音色可选

> 版本号：V4.18.7（接 V4.18.6 USB 小票机直驱）
> 日期：2026-09-11
> 范围：统一 TTS 引擎（backend/public/tts.js）+ 收银台设置（pwa/cashier.js）+ 迁移 086；老板端零改动

---

## 一、需求与现状

**需求**：收银端播报语音太生硬、不拟人化；收银端设置中可选择多种语音；默认用老板端的播报语音。

**现状分析**：
- 拟人引擎 `backend/public/tts.js`（V4.13.8）本就支持多音色/语速/音调，读老板端「通用设置→语音播报」的
  `voice.tts.mode / voice.tts.voice / voice.tts.rate / voice.tts.pitch`（055 迁移种子）；
  但**收银台没有任何入口**可选音色，且默认挑选逻辑存在「生硬」根因：
  `pickVoice` 兜底段 `vs.find(v => !isNatural(v))` 会**优先命中本机机械男声**
  （如 Windows 的 Microsoft Kangkang）——浏览器无 Edge 拟真在线声时（如 Chrome），听感生硬正是这么来的。

## 二、实现

### 2.1 默认音色挑选拟人化（tts.js pickVoice 兜底重排）

```
指定音色 → 拟真人声(Natural，女声优先 晓晓/晓伊/慧慧) → Google 在线声 → 本地女声(晓/慧/瑶/婷) → 首个本地声
```

不动用户配置（S.voice 指定仍最高优先），只修「没配置时落到机械男声」的默认路径。

### 2.2 收银台音色/语速可选，空值=跟随老板端（tts.js loadCfg）

```
基准：voice.tts.*（老板端全局）
覆盖：pos.cashier.tts.voice / rate / pitch 非空时覆盖；空串/未设置=完全跟随老板端
```

覆盖键按「非空才生效」合并，老板端换音色时未单独设置的收银台自动跟随。

### 2.3 收银设置弹窗（cashier.js openSettings）

- **播报音色**下拉：`跟随老板端设置`（默认）+ 本机全部中文音色实时枚举（标注（拟真）/（本地））；
- **播报语速**下拉：跟随老板端 / 0.85 / 1 / 1.1 / 1.25 倍；
- **🔊 试听当前音色**按钮：临时套用下拉当前选择播报样句（不动库），保存后 `PwaTTS.loadCfg(true)` 立即生效；
- 提示文案引导选「拟真」在线人声（Edge 自带晓晓/云希等最接近真人）。

### 2.4 迁移 086（幂等种子）

`pos.cashier.tts.voice`（string，''）、`pos.cashier.tts.rate`（string，''），收银台组，remark 说明空=跟随老板端。
（PUT /settings 仅允许已存在键，故需种子。）

### 2.5 SW

`pwa-shell-v52 → v53`。

## 四、真机建议

1. 电脑 Chrome 打开收银端：设置→播报音色→试听，选带「（拟真）」的声（若本机无，用 Edge 打开即有晓晓/云希等在线拟真声）；
2. 不单独设置时确认播报与老板端音色一致；老板端改音色后收银台重启后跟随；
3. 语速 1.1 倍左右通常听感最自然（收银场景偏快）。
