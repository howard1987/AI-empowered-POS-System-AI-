# V4.16.1 · 天气因素接入 AI 决策（P10）

> 日期：2026-09-10 · 前置：V4.16.0（AI 路线 P6~P9）· 迁移：072 · 后端 3100 / 前端 8088 在线

## 一、本期目标
把本地天气预报接入智能决策：雨天/雪天客流下降、高温冷饮冰品走量、骤降温速冻火锅走量——
天气作为「备货建议的外生变量」，只做增量建议与人话提示，**下单权始终在人**。
外部数据沿用条码链「宁缺毋滥」原则：拉取失败静默降级缓存旧值，绝不阻塞收银与备货主流程。

## 二、数据源与降级（backend/src/modules/weather.service.ts，新建）
- **默认 Open-Meteo**：免注册免 Key 直用；城市名经 Open-Meteo Geocoding（支持中文）自动换算经纬度，进程内缓存。
- **可选和风天气**：设置页填 `ai.weather.qweather_key` 自动切主源（国内精度更高）；
  新账号专属 Host 走 `{host}/geo/v2/city/lookup` + `{host}/v7/weather/3d`（`X-QW-Api-Key` 头），官方免费域名自动走 geoapi/devapi；`ai.weather.qweather_host` 可配。
- **缓存**：`weather_cache` 表（store_id+forecast_date 唯一，今日+未来 3 天），1 小时新鲜期 + 进程内 30 分钟拉取节流；upsert 覆盖。
- **降级**：外网失败/城市解析失败 → 读缓存旧值（stale 标记）；无缓存返回空+note，全链路不抛错。

## 三、天气经营因子（dayFactor / factorsOf，导出共用）
| 场景 | 判定 | 客流 traffic | 品类加成 |
|---|---|---|---|
| 雨 | condText 含「雨」或降水≥0.1mm | ×0.9 | 泡面/速食/罐头/速冻 ×1.15；雨伞雨衣 ×1.4 |
| 雪 | condText 含「雪」 | ×0.8 | 同上 + 防滑保暖 ×1.4 |
| 高温 | 最高温 ≥32℃ | — | 饮料/水/冰品/雪糕/啤酒/乳 ×1.3 |
| 低温/骤降 | 最高温 ≤5℃ 或较前日降 ≥8℃ | — | 速冻/火锅/饺子/汤圆 ×1.25 |

品类按**品类名关键词命中**（不匹配不加成）；因子与理由写入建议 reason，老板能看懂「为什么多订」。

## 四、AI 引擎与端点
- `AibrainEngine.weatherStock(storeId)`（新增应用，进 refresh 闭环）：
  - 当日去重（同规则「天气因素备货」待处理只生成一批，与节假日备货共用「备货」域、按 payload.rule 区分）；
  - 有 forecast_snapshots → 分品类量化（base3 × (factor−1)，客流系数叠加），无预测 → 文字版建议（同样落库留痕）；
  - 天气平稳（无雨雪/无极端温度）→ 不生成，返回 note。
- `GET /brain/weather`（登录即可）：天气卡数据（enabled/provider/city/days/factors/stale/note）。
- `POST /brain/run/weatherStock`：手动运行（决策中心按钮）。
- **qa 天气路由**：`/天气|气温|下雨|下雪|降温|几度|冷不冷|热不热/` → 三天预报+经营提示（Ollama 开启时自动增强为自然句）。
- 预置问题清单新增「今天天气怎么样？」。

## 八、坑与修复（本期踩坑记录）
1. **pg DATE → JS Date**：`weather_cache.forecast_date` 被 pg 驱动解析为 Date，`String(x).slice(0,10)` 得到 "Thu Sep 10"（qa 显示 "ep 10"）——必须显式格式化（同 fmtD 逻辑）。
2. **JSONB 种子空串/中文**：system_settings.value 是 JSONB，`''` 非法、`'北京'` 也非法——字符串必须带 JSON 双引号：`'"北京"'`、空串写 `'""'`（参考 001 中 `'"B"'` 先例）。
3. **晴天雨具误加成**：条件写成 `isRainy || tmax<32` 导致晴天也给雨具 ×1.4——已收紧为仅雨天/雪天。
4. **weatherStock 漏当日去重**：连点重复生成建议——补 payload.rule 级去重。
5. **缓存路径 provider 标「缓存」**：缓存命中返回实际落库的 provider（open-meteo/qweather），不再误导。
