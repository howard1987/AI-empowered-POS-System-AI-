# 超市收银系统 V4.19.0 版本说明
## P15.5 十项收口 + 回车键盘流 + 静默打印根治（2026-09-11）

> 来源：用户三项反馈 ①购物车有商品回车即「结算」，支付后回车即「新的一单」；②仍会弹打印预览；③执行 P15.5 及 P16。
> 本版覆盖 ①②+P15.5 十项；P16 见 V4.20.0。

---

## 一、回车键盘流（收银台）

| 场景 | 行为 |
|---|---|
| 购物车为空 + 回车 | 不动作 |
| 购物车有商品 + 回车 | 直接打开结算弹窗（免点「结 算」按钮） |
| 结算弹窗「顾客实收」输入后回车 | 确认收款（V4.18.9 已有，保留） |
| 收款成功弹窗 + 回车 | =「新的一单」（pwaConfirm 新增 `enterOk` 捕获回车，弹窗关闭、购物车已清空） |

- 扫码枪结束回车因 `scanBuf≥6` 先命中扫码分支，不受回车结算影响；弹窗打开时全局键不抢（`.modal-mask` 一并纳入守卫）。

## 二、静默打印根治（不再弹预览）

- **新策略**：已配置默认小票机（网口/串口/USB 系统驱动 RAW）时，直驱失败/不可达 → **不再回落浏览器打印**（杜绝结账弹预览），明示「未出票（已留痕）」+ 设备埋点，可「补打上一单」重试。
- **未配置默认机**：按新设置 `pos.print.browser_fallback`（收银设置「浏览器兜底打印（弹预览）」，默认开）决定是否走浏览器 iframe 兜底；设为「关」则绝不弹预览。
- 手动「补打上一单」保持用户主动触发，仍可用浏览器兜底。

## 三、P15.5 十项（§13.14 定稿口径）

| # | 项 | 落地 |
|---|---|---|
| 1 | 分单（拆出另结） | 扫码栏新增「分单」：勾行+数量（称重行 0.05 步进）→ 后端 `POST /pos/held/split-validate` 校验（防 0 行/超量/商品不存在/同行重复）→ `POST /pos/held` 生成新挂起单；本车扣减拆出量；**优惠在拆分后各自小票重算**（原车已套券/折扣/积分/抹零清空）；整单全拆拦截（请用挂单） |
| 2 | 部分支付两态（D2） | 挂账页加「已付部分现金」输入（联动显示转挂账部分）：落单生成「现金 X + 赊账 Y」两行支付，`member_credits` **只记 Y**；赊账单笔限额按 Y 校验（店长放行不变） |
| 3 | 离线退货（C2） | 断网时现金单退款 → 复用离线暂存队列（`kind:'refund'`，clientRef 幂等），恢复联网自动补传；**电子通道退款强制在线**明示；refund-lookup 返回主支付渠道 `payChannel` 供分流；`sale_refunds` 加 `client_ref` 列（迁移 088），服务端同 ref 重发返回原单（`dedup:true`）不重复退款 |
| 4 | 蓝牙音箱语音出口 | Web BLE 探测：选设备→GATT 连接→探测可写特征；纯 A2DP 音箱明确提示「浏览器无法转发语音流，播报继续走本机喇叭」；有厂商写通道但协议未收录同样明示（收银设置「连接/探测」入口） |
| 5 | 语音查价（独立入口） | 顶栏「🎤 问价」：语音识别（或手输）商品名 → 前缀>包含匹配 → 命中播报**售价+库存**（多候选列出点选）；不打断当前购物车 |
| 6 | 消息静默收纳 | 顶栏「🔔 消息」铃铛+红点：打印失败/补传失败/设备告警收进列表（时间+文本），点开查看，「全部已读」清红点；不弹窗打断 |
| 7 | 挂单列表搜索+排序 | 取单弹窗：搜索框（单号/会员/商品名/挂单人）+「按时间↑ / 按金额↓」排序切换；删除后列表原地刷新 |
| 8 | 券码手输兜底 | `member_coupons` 加 `code`（`MC+8位序号`，迁移 088 回填+发券自动生成）；结算页「输券码」→ `POST /coupons/lookup-code` 校验归属会员+状态+有效期 → 选用；纸质券可印码 |
| 9 | 设备埋点四类 | 新表 `device_events`（迁移 088）+ `POST/GET /device/events`：打印失败/连接失败/补传失败/秤离线统一上报（静默不阻断）；补传失败记埋点并保留队列重试；收银设置「设备异常记录」可查近 20 条 |
| 10 | 设备告警推送老板端 | warn 级埋点同步 `notifyStaff`（kind=device_warn，同小时 batchKey 去重防缺纸风暴）→ 老板端消息中心+角标（复用 /finance/notices 通道） |
